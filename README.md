# Game Localization Discovery Archive

한글화할 게임을 찾기 위해 **플랫폼·국가·언어에 제한을 두지 않고 후보를 발굴·조사·평가하는 개인 아카이브**입니다.

단순히 재미있어 보이는 게임을 모으는 목록이 아니라, 실제 한글화 프로젝트 후보를 고르기 위해 **게임 자체의 가치와 한글화 가능성**을 함께 기록합니다.

> [!IMPORTANT]
> 이 아카이브는 일본 게임이나 PlayStation 2에 한정하지 않습니다.
> 콘솔·휴대기·PC를 모두 대상으로 하며, 후보는 **기종별 폴더**로 구분합니다.

## 플랫폼별 현황

| 플랫폼 | 등록 후보 | 우선 후보 | 바로가기 |
|---|---:|---:|---|
| PlayStation 2 | 12 | 8 | [PS2 후보 보기](platforms/ps2/README.md) |

다른 플랫폼은 후보가 생기는 시점에 `platforms/<platform>/` 아래에 추가합니다.

## 이 아카이브에서 확인하는 것

게임을 등록할 때 가능한 범위에서 아래 항목을 확인합니다.

- 정확한 원제 / 발매일 / 개발사 / 발매사 / 장르
- 원산지와 원문 언어
- 여성향·오토메·BL 여부 / 남성향 여부
- 외부 평점과 표본 수
- 스포일러를 최소화한 시놉시스
- 작품의 특징과 장단점
- 예상 플레이타임
- 공식 한국어판 여부
- 공개 유저 한글패치 여부
- 타 기종 이식 / 원작·이식·확장판 관계
- 플랫폼별 추가·삭제 콘텐츠
- 리마스터·리메이크 여부
- 현재 기준 추천 버전
- 실제 게임 스크린샷
- 한글화 후보로서의 가치
- 텍스트량 / 추출 난이도 / 폰트 / UI 이미지 / 영상 자막 / 제어문자 등 한글화 기술 난이도
- 실기·에뮬레이터 검수 난이도

> [!NOTE]
> 기술 난이도가 아직 분석되지 않은 게임은 추측해서 채우지 않고 **미확인**으로 남깁니다.

## 평가 축

### 발굴 추천도

게임 자체를 지금 발굴해서 플레이할 가치에 대한 큐레이션 점수입니다. 외부 리뷰 점수를 그대로 환산하지 않습니다.

### 한글화 우선도

게임의 매력, 한국어 접근성, 기존 한국어화 여부, 다른 버전의 존재 등을 함께 보고 실제 한글화 후보로서의 우선순위를 판단합니다.

### 한글화 난이도

텍스트 추출·재삽입, 폰트, UI 이미지, 영상, 실행 파일 수정, 제어코드, 플랫폼별 패치 방식과 검수 부담 등을 기준으로 별도로 기록합니다.

## 상태 기준

- 💎 **우선 후보**: 실제 확보·분석·한글화 검토 우선순위가 높은 게임
- 🟢 **후보**: 충분히 검토할 가치가 있는 게임
- 🟡 **보류**: 장점은 있지만 볼륨·평가·기술 난이도·접근성 등의 이유로 후순위
- 🔴 **패스**: 취향 또는 프로젝트 조건에 맞지 않아 제외

## 한글패치 표기 원칙

`확인 못함` 또는 `공개적으로 확인되지 않음`은 **현재 공개 배포 중인 한국어 패치를 조사했지만 찾지 못했다**는 뜻입니다. 비공개 패치까지 포함해 세상에 절대로 존재하지 않는다는 의미로 사용하지 않습니다.

공식 한국어판과 유저 한글패치는 반드시 구분합니다.

## 저장소 구조

```text
.
├─ README.md
├─ platforms/
│  └─ ps2/
│     ├─ README.md
│     └─ games/
│        └─ <game>.md
└─ templates/
   └─ game-entry-template.md
```

플랫폼이 추가되면 같은 구조로 `platforms/psp/`, `platforms/switch/`, `platforms/pc/`처럼 확장합니다.

## 새 게임 등록

새 후보를 조사할 때는 [`templates/game-entry-template.md`](templates/game-entry-template.md)를 기준으로 작성합니다. 이미 등록된 과거 문서는 기존 조사 내용을 보존하며, 다시 검토할 때 한글화 기술 난이도 항목을 보강합니다.

---

이 아카이브는 게임 원본, 롬 이미지, 실행 파일, 추출된 전체 스크립트 등 저작권 자산을 배포하기 위한 저장소가 아닙니다. 스크린샷은 작품 식별과 조사 기록을 위해 출처를 명시해 링크하거나 임베드합니다.
