# Game Localization Discovery Archive

한글화할 게임을 찾기 위해 **플랫폼·국가·언어에 제한을 두지 않고 후보를 발굴·조사·평가하는 개인 아카이브**입니다.

단순히 재미있어 보이는 게임을 모으는 목록이 아니라, 실제 한글화 프로젝트 후보를 고르기 위해 **게임 자체의 가치와 한글화 가능성**을 함께 기록합니다.

> [!IMPORTANT]
> 이 아카이브는 일본 게임이나 PlayStation 2에 한정하지 않습니다. 콘솔·휴대기·PC를 모두 대상으로 하며 후보는 **기종별 폴더**로 구분합니다.

## 이 아카이브에서 확인하는 것

게임을 등록할 때 가능한 범위에서 아래 항목을 확인합니다.

- 정확한 원제 / 영문·로마자 제목 / **국내 통용 한글 제목** / 발매일 / 개발사·발매사 / 장르
- 원산지와 원문 언어
- 외부 평점과 표본 수
- 스포일러를 최소화한 시놉시스
- 작품의 특징과 장단점
- 예상 플레이타임
- 공식 한국어판 여부
- 공개 유저 한글패치 여부
- 타 기종 이식 / 원작·이식·확장판 관계
- 플랫폼별 추가·삭제 콘텐츠
- 리마스터·리메이크 여부
- 현재 기준 추천 버전
- 실제 게임 스크린샷
- 한글화 후보로서의 가치
- 텍스트량 / 추출 난이도 / 폰트 / UI 이미지 / 영상 자막 / 제어문자 등 한글화 기술 난이도
- 실기·에뮬레이터 검수 난이도

> [!NOTE]
> 한글 제목은 가능한 경우 나무위키·국내 블로그·게임 DB 등에서 실제 사용례를 확인해 가장 통용되는 표기를 사용합니다. 통용 표기가 명확하지 않으면 억지로 의역하지 않고 자연스러운 음역을 우선합니다.
>
> 기술 난이도가 아직 분석되지 않은 게임은 추측해서 채우지 않고 **미확인**으로 남깁니다.

## 평가 축

### 발굴 추천도

게임 자체를 지금 발굴해서 플레이할 가치에 대한 **작품 평가 점수**입니다. 외부 리뷰 점수를 그대로 환산하지 않고, 시나리오 완성도·구조·캐릭터 활용·연출·게임 시스템·반복 부담·판본 완성도와 여러 외부 평가의 일관성을 종합해 판단합니다.

**사용자 취향 적중도는 별점에 가산하지 않습니다.** 취향에 잘 맞더라도 작품 완성도가 부족하면 4.0 이상을 주지 않고, 취향과 별개로 객관적인 작품 평가와 추천 이유를 구분해서 기록합니다.

- ⭐⭐⭐⭐⭐ **5.0**: 장르 내에서도 손꼽힐 정도로 완성도가 높고 큰 약점이 드문 작품
- ⭐⭐⭐⭐½ **4.5**: 강력 추천. 뚜렷한 강점과 높은 완성도를 갖고 약점보다 장점이 확실히 우세한 작품
- ⭐⭐⭐⭐ **4.0**: 우수작. 취향을 빼고 봐도 작품 전체 완성도와 추천 근거가 충분히 강한 우수작
- ⭐⭐⭐½ **3.5**: 플레이 후보. 분명한 장점과 발굴 가치가 있으나 완성도·평가 편차·반복·구조적 약점 등으로 4.0에는 못 미치는 작품
- ⭐⭐⭐ **3.0 이하**: 특별한 이유가 없다면 기본적으로 등록하지 않음

> [!NOTE]
> **2026-09-12 점수 기준 재정비:** 기존 PS2 4.0 이상 13개 작품을 취향 가산 없이 전수 재검증했고, 9개가 4.0 이상으로 남았습니다. 현재 4.5 유지작은 없습니다. 작품 별점과 한글화 우선도는 서로 다른 축으로 관리합니다.

### 한글화 우선도

작품의 매력, 한국어 접근성, 기존 한국어화 여부, 대체 가능한 다른 버전, 예상 검수 부담 등을 함께 보고 실제 프로젝트 후보로서의 우선순위를 판단합니다.

- 🔥 **A**: 실제 프로젝트 후보로 먼저 파일 구조를 분석할 가치가 큰 작품
- **B**: 충분히 한글화할 가치가 있지만 판본 선택·검수량·상대 우선순위를 함께 비교해야 하는 작품
- **C**: 후보로 유지하지만 현재 A/B급보다 한글화 프로젝트 우선순위가 낮은 작품

> 한글화 우선도는 **발굴 추천도 및 한글화 기술 난이도와 별개**입니다. A급이라도 작품 별점은 3.5일 수 있고, C급이라도 게임 자체 완성도는 높을 수 있습니다.

### 한글화 난이도

텍스트 추출·재삽입, 폰트, UI 이미지, 영상, 실행 파일 수정, 제어코드, 플랫폼별 패치 방식과 검수 부담 등을 기준으로 기록합니다.

실제 게임 파일 또는 신뢰할 수 있는 기술 자료를 분석하기 전에는 난이도를 단정하지 않고 **미확인**으로 둡니다.

## 상태 기준

- 💎 **우선 후보**: 발굴 추천도 4.0 이상인 작품
- 🟢 **후보**: 발굴 추천도 3.5인 작품
- 🟡 **보류**: 장점은 있지만 볼륨·평가·기술 난이도·접근성 등의 이유로 후순위
- 🔴 **패스**: 객관적 작품 평가 또는 프로젝트 조건상 제외

## 한글패치 표기 원칙

`확인 못함` 또는 `공개적으로 확인되지 않음`은 **현재 공개 배포 중인 한국어 패치를 조사했지만 찾지 못했다**는 뜻입니다. 비공개 패치까지 포함해 세상에 절대로 존재하지 않는다는 의미로 사용하지 않습니다.

공식 한국어판과 유저 한글패치는 반드시 구분합니다.

## 저장소 구조

```text
.
├─ README.md
├─ platforms/
│  ├─ ps2/
│  │  ├─ README.md
│  │  └─ games/
│  │     └─ <game>.md
│  ├─ psp/
│  │  ├─ README.md
│  │  └─ games/
│  │     └─ <game>.md
│  └─ psvita/
│     ├─ README.md
│     └─ games/
│        └─ <game>.md
└─ templates/
   └─ game-entry-template.md
```

플랫폼이 추가되면 같은 구조로 `platforms/switch/`, `platforms/pc/`처럼 확장합니다.

## 새 게임 등록

새 후보를 조사할 때는 [`templates/game-entry-template.md`](templates/game-entry-template.md)를 기준으로 작성합니다.

> [!IMPORTANT]
> **새 작품을 추가하거나 한글화 우선도를 수정할 때마다 각 플랫폼의 후보 표를 `🔥 A → B → C` 순으로 다시 정렬합니다.**

현재 PS2 후보 97개는 동일한 핵심 양식으로 정리되어 있으며, PSP·PS Vita도 같은 기준으로 새 후보를 누적합니다. 모든 플랫폼에서 **한글화 가치 / 우선도 / 기술 난이도 표**를 포함하고, 실제 파일 분석 전인 기술 항목은 `미확인`으로 유지합니다.
