## 2026-10-17 PS1 《serial experiments lain》 작품성·한국어 웹 자막 보존

[1998년 일본 PS1 공식 2CD 상세 평가](games/serial-experiments-lain.md)는 **작품성 4.0/5, 개인 별도 추천 8.3/10·역사 순위 미산정**입니다. Bangumi PS1 7.8/10·68명과 GameFAQs PS1 Good·25명 및 2018 제작진 회고·PS1 리뷰의 비판을 별도로 조사했습니다. **[lainTSX 웹 한국어 언어 선택](https://3d.laingame.net/)**과 [한국어 자막 원본 667개](https://github.com/laingame-net/lainvtt/tree/main/ko) 확인으로 한국어 대안이 이미 있음을 구분했습니다. 영어판 673개에 대한 파일 대응은 **99.1%**지만 문장 완역률·원 PS1 ISO의 한국어 구동·전 엔딩 QA를 뜻하지 않습니다. 2026년 Switch 홈브류·Windows/Mac/Linux 코드 복원은 공식 게임판이나 PSP판 별도 출시가 아닙니다. **🟡 한국어 대안 존재·신규 활성 번역 제외, A/B/C 우선도 미부여**, 작품성 평가 후보군에만 1행을 더해 사이트에서 검색/찜이 가능합니다. 기존 《ToHeart》 평점·상태, 타 플랫폼 순위와 갱신 전 역사 자료는 그대로 보존합니다. **PS1 현행 총 2건/활성 신규 번역 후보 0건**입니다.



## 2026-10-17 사용자 요청: 레인 PS1 기본 화면 등록

[《serial experiments lain》 1998 PS1판](games/serial-experiments-lain.md)은 동일 게임·동일 플랫폼에서 작품 평가로 이미 기록됐지만 **기존 표의 「목록 구분」이 후보군이어서 PS1 ‘기존 목록’ 화면에는 표시되지 않았다**. 사용자 요청에 따라 **원래 한 행을 후보군 → 기존 목록으로 이동**해 [PS1 기본 목록](https://dollars-archive.github.io/Game-Localization-Discovery-Archive/?platform=ps1&view=active)에서도 바로 볼 수 있도록 수정했다. **4.0/5·8.3/10·순위 미산정** 및 외부 평가·문서 경로·찜 키를 그대로 보존했고, 한국어 웹 번역 대안이 있어 **PS1 신규 한글화 활성 후보에서는 제외/A·B·C 미부여** 판정도 유지한다.

PS1 현재 보존 **2건** 중 웹 ‘기존 목록’에 작품성 표시 **1건(레인)**, ‘후보군’ 기록 **1건(투하트)**, 실제 신규 한글화 활성 후보 **0건**이다. 이 사용자 지정 표시는 번역 착수 자격이나 패치 신규 작업 선정을 뜻하지 않는다. 기존 평가 점수와 다른 플랫폼 기록을 변경하지 않는다.
