## 2026-10-17 《serial experiments lain》 PS1 작품성·한국어 웹 대안 평가

[《serial experiments lain》 1998년 PS1 오리지널 2CD 상세 조사](games/serial-experiments-lain.md)를 **작품성 ⭐⭐⭐⭐☆ 4.0/5, 별도 정성 추천 8.3/10**으로 기록했습니다. Pioneer LDC의 1998-11-26 정식 일본 발매 [SLPS-01603/01604 두 CD](https://gamefaqs.gamespot.com/ps/574938-serial-experiments-lain/data)의 게임이며, 같은 이름의 애니메이션과 다른 상담사 **요네라 토코** 중심 기록 탐색 스토리입니다. [Bangumi PS1 평가 7.8/10·68명](https://bangumi.tv/subject/145972), [GameFAQs Good·25명](https://gamefaqs.gamespot.com/ps/574938-serial-experiments-lain), [2018년 원 작가·총괄·원화 관계자 3명의 인터뷰](https://www.4gamer.net/games/999/G999905/20180905022/), 2015~2023년 PS1 독립 비평의 장단점을 종합했습니다.

**한국어 대안은 미존재가 아닙니다.** 팬의 [lainTSX 웹 재구현](https://3d.laingame.net/)이 Korean을 선택 언어로 제공하고, [공개 번역 원본 ko 667건](https://github.com/laingame-net/lainvtt/tree/main/ko)과 [영어 en 673건](https://github.com/laingame-net/lainvtt/tree/main/en)을 PS1 주요 상담·일기·영상 텍스트 분류별로 대조했습니다. 누락 6개는 Notes.vtt 및 Xa0002~0006.vtt로, 파일 수 대응 **99.1%는 문장 번역률이나 전편 완주 검수 완료율이 아닙니다.** 오리지널 PS1 2CD 직접 실행 한국어 패치는 별도 미확인입니다. 실제 한국어 서사 접근성의 다른 환경 대안이 있어 **🟡 신규 PS1 한글화 활성 후보 제외 / A·B·C 미부여 / 전체 작품 평가의 후보군에 보존**했습니다.

**PS1 현행 등록·보존 2개 / 활성 번역 후보 0 / 발굴 우선 0 / 한글화 A급 0**이며 기존 《ToHeart》 4.0점·8.2점·후보 상태와 2026-10-08 타 플랫폼 역사 순위·사이트 링크는 그대로 유지했습니다. [2026년 공개 실제 PS1 C 코드 복원](https://github.com/Y0oshi/lain-psx-decompiled)은 원판의 미래 기술적 연구 기반이지만 Sony/Pioneer 공식 리마스터는 아닙니다.



## 2026-10-17 사용자 요청: 《serial experiments lain》 PS1 기본 목록 표시

[《serial experiments lain》](games/serial-experiments-lain.md)은 PS1 플랫폼에 이미 등록된 1998년 **PS1 정식판** 평가 기록이었으나, 웹 작품 평가 원본 [recommendations.md](recommendations.md)에서 **「후보군」으로 분류된 탓에 ‘기존 목록’ 필터에 표시되지 않았다**. 사용자 요청에 따라 **기존 한 행만 「기존 목록」으로 이동**했으며, [PS1 기본 화면에서 레인 바로 보기](https://dollars-archive.github.io/Game-Localization-Discovery-Archive/?platform=ps1&view=active)와 [PS1 전체 평가](https://dollars-archive.github.io/Game-Localization-Discovery-Archive/?platform=ps1) 양쪽에 표시하도록 했다.

작품성 **4.0/5**, 추천 **8.3/10**, 한국어 웹 번역([lainTSX Korean](https://3d.laingame.net/), 자막 ko **667건**)과 PS1 원본 직접 한글화 미확인을 모두 보존한다. 이 **사용자 지정 기본 표시 1건은 신규 번역 활성 후보 수에 포함하지 않으며**, 한글화 우선도 **미부여**, **PS1 활성 한글화 후보 0건**이다. 다른 게임 《ToHeart》는 기존 **후보군 1건**으로 유지한다. PS1 전체 보존 **2건**, 발굴 우선 **0건**, 한글화 A **0건** 유지. 다른 플랫폼 기록·찜 키·사이트 코드 무변경.

## 2026-10-17 《아카가와 지로 야상곡》 PS1 1998년판 신규 평가

[PS1 《赤川次郎 夜想曲》 1998-07-16 SLPS-01462 평가 문서](games/akagawa-jirou-yasoukyoku.md)를 **3.5/5·추천 7.6/10**으로 신규 보존했습니다. 사용자가 입력한 《本に招かれた殺人》 부제는 **PS1 최초 제품이 아닌 2008 DS 합본 공식 명칭**입니다. 2001 PS1 《夜想曲2》는 별도 제품이며, DS에는 1+2편이 모두 담깁니다. [Marvelous PS1 공식](https://www.marv.jp/titles/cs/199/) / [DS NTR-P-YOQJ 공식](https://www.marv.jp/titles/cs/512/). PS1 이용자 Gavas **5.0/5·5건**의 좋은 평가와 반복·저장 편의의 약점을 종합해 작품성을 판단했습니다.

**한국어 상태:** [RetroDB #5136](https://retrodb.info/krpatch/5136/%EC%95%84%EC%B9%B4%EA%B0%80%EC%99%80-%EC%A7%80%EB%A1%9C-%EB%AF%B8%EC%8A%A4%ED%84%B0%EB%A6%AC-%EB%8B%AC%EC%9D%98-%EB%B9%9B-%EA%B0%80%EB%9D%BC%EC%95%89%EC%9D%80-%EC%A2%85%EC%9D%98-%EC%82%B4%EC%9D%B8)의 패치 제목은 **《달의 빛》**, 연결된 게임 출시일·스토리는 **《야상곡》**이어서 서로 다른 DS 게임 데이터가 섞였습니다. 실제 패치 대상 ROM과 완역 범위를 검증하지 못했으므로 신규 PS1 번역 후보 자격을 **🟡 보류·한글화 우선도 미부여**로 분류하되, 사용자 요청 작품성 평가는 **PS1 기본 ‘기존 목록’에 표시**합니다.

**PS1 전체 평가/보존 3건 / 웹 기본 표시 2건(레인·야상곡) / 후보군 1건(투하트) / 신규 번역 활성 0건 / 발굴 우선 0건 / 한글화 A 0건.** 다른 작품 파일과 2026-10-08 역사 점수·개인 찜 키는 변경하지 않았습니다.
