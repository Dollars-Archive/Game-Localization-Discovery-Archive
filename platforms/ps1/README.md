Pioneer LDC의 1998-11-26 정식 일본 발매 [SLPS-01603/01604 두 CD](https://gamefaqs.gamespot.com/ps/574938-serial-experiments-lain/data)의 게임이며, 같은 이름의 애니메이션과 다른 상담사 **요네라 토코** 중심 기록 탐색 스토리입니다. **한국어 대안은 미존재가 아닙니다.** 팬의 [lainTSX 웹 재구현](https://3d.laingame.net/)이 Korean을 선택 언어로 제공하고, [공개 번역 원본 ko 667건](https://github.com/laingame-net/lainvtt/tree/main/ko)과 [영어 en 673건](https://github.com/laingame-net/lainvtt/tree/main/en)을 PS1 주요 상담·일기·영상 텍스트 분류별로 대조했습니다. 누락 6개는 Notes.vtt 및 Xa0002~0006.vtt로, 파일 수 대응 **99.1%는 문장 번역률이나 전편 완주 검수 완료율이 아닙니다.** 오리지널 PS1 2CD 직접 실행 한국어 패치는 별도 미확인입니다. 실제 한국어 서사 접근성의 다른 환경 대안이 있어 **🟡 신규 PS1 한글화 활성 후보 제외 / A·B·C 미부여 / 전체 작품 평가의 후보군에 보존**했습니다.

**PS1 현행 등록·보존 2개 / 활성 번역 후보 0 / 발굴 우선 0 / 한글화 A급 0**이며 기존 《ToHeart》 4.0점·8.2점·후보 상태와 2026-10-08 타 플랫폼 역사 순위·사이트 링크는 그대로 유지했습니다. [2026년 공개 실제 PS1 C 코드 복원](https://github.com/Y0oshi/lain-psx-decompiled)은 원판의 미래 기술적 연구 기반이지만 Sony/Pioneer 공식 리마스터는 아닙니다.



## 2026-10-17 사용자 요청: 《serial experiments lain》 PS1 기본 목록 표시

[《serial experiments lain》](games/serial-experiments-lain.md)은 PS1 플랫폼에 이미 등록된 1998년 **PS1 정식판** 평가 기록이었으나, 웹 작품 평가 원본 [recommendations.md](recommendations.md)에서 **「후보군」으로 분류된 탓에 ‘기존 목록’ 필터에 표시되지 않았다**. 사용자 요청에 따라 **기존 한 행만 「기존 목록」으로 이동**했으며, [PS1 기본 화면에서 레인 바로 보기](https://dollars-archive.github.io/Game-Localization-Discovery-Archive/?platform=ps1&view=active)와 [PS1 전체 평가](https://dollars-archive.github.io/Game-Localization-Discovery-Archive/?platform=ps1) 양쪽에 표시하도록 했다.

작품성 **4.0/5**, 추천 **8.3/10**, 한국어 웹 번역([lainTSX Korean](https://3d.laingame.net/), 자막 ko **667건**)과 PS1 원본 직접 한글화 미확인을 모두 보존한다. 이 **사용자 지정 기본 표시 1건은 신규 번역 활성 후보 수에 포함하지 않으며**, 한글화 우선도 **미부여**, **PS1 활성 한글화 후보 0건**이다. 다른 게임 《ToHeart》는 기존 **후보군 1건**으로 유지한다. PS1 전체 보존 **2건**, 발굴 우선 **0건**, 한글화 A **0건** 유지. 다른 플랫폼 기록·찜 키·사이트 코드 무변경.

## 2026-10-22 《제절초: 소생편》 PS1 리메이크 최초 활성 B급 등록

[1999년 일본 정식 PS1 `SLPS-01645` 상세 평가](games/otogirisou-sosei-hen.md)를 **⭐⭐⭐½☆ 3.5/5 · B급 활성 번역 후보 · 2026 신규 정성 리뷰 7.3/10(역사 순위 미산정)**으로 등록했다. [Famitsu PS1 1999-03-25 발매](https://www.famitsu.com/game/title/18067/page/1), [PSX DataCenter SLPS-01645 실제 인게임](https://psxdatacenter.com/games/J/S/SLPS-01645.html), [Gavas PS1 3.8/5·6건](https://www.gavas.jp/products/detail.php?product_id=10206), [2014 Dengeki PS1 아카이브스 직접 리뷰](https://dengekionline.com/elem/000/000/870/870914/)로 판본·작품성을 검증했다. Famitsu 당시 **30/40 (8·7·8·7)**은 2차 문헌의 재록이며, 현재 [Famitsu 웹 원문에는 개별 수치가 공개되어 있지 않음](https://www.famitsu.com/game/title/18067/reviews)을 구분했다.

1992 SFC 원작과 달리 1999 PS1 `蘇生篇`은 **전체 그래픽·문장 개작·나미 새 관점 ZAP·엔딩 이후 반전 장면·DualShock 효과**가 추가된 정식 **리메이크**이다. 한글화 후보 기준의 구작만 한국어화된 리메이크 예외를 적용한다.
