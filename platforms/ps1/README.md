## 2026-10-17 《serial experiments lain》 PS1 작품성·한국어 웹 대안 평가

[《serial experiments lain》 1998년 PS1 오리지널 2CD 상세 조사](games/serial-experiments-lain.md)를 **작품성 ⭐⭐⭐⭐☆ 4.0/5, 별도 정성 추천 8.3/10**으로 기록했습니다. Pioneer LDC의 1998-11-26 정식 일본 발매 [SLPS-01603/01604 두 CD](https://gamefaqs.gamespot.com/ps/574938-serial-experiments-lain/data)의 게임이며, 같은 이름의 애니메이션과 다른 상담사 **요네라 토코** 중심 기록 탐색 스토리입니다. [Bangumi PS1 평가 7.8/10·68명](https://bangumi.tv/subject/145972), [GameFAQs Good·25명](https://gamefaqs.gamespot.com/ps/574938-serial-experiments-lain), [2018년 원 작가·총괄·원화 관계자 3명의 인터뷰](https://www.4gamer.net/games/999/G999905/20180905022/), 2015~2023년 PS1 독립 비평의 장단점을 종합했습니다.

**한국어 대안은 미존재가 아닙니다.** 팬의 [lainTSX 웹 재구현](https://3d.laingame.net/)이 Korean을 선택 언어로 제공하고, [공개 번역 원본 ko 667건](https://github.com/laingame-net/lainvtt/tree/main/ko)과 [영어 en 673건](https://github.com/laingame-net/lainvtt/tree/main/en)을 PS1 주요 상담·일기·영상 텍스트 분류별로 대조했습니다. 누락 6개는 Notes.vtt 및 Xa0002~0006.vtt로, 파일 수 대응 **99.1%는 문장 번역률이나 전편 완주 검수 완료율이 아닙니다.** 오리지널 PS1 2CD 직접 실행 한국어 패치는 별도 미확인입니다. 실제 한국어 서사 접근성의 다른 환경 대안이 있어 **🟡 신규 PS1 한글화 활성 후보 제외 / A·B·C 미부여 / 전체 작품 평가의 후보군에 보존**했습니다.
