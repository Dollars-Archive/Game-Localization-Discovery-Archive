> 한글화 우선도는 **발굴 추천도 및 기술 난이도와 별개**입니다. 3.5점 작품도 PSP 독자 콘텐츠·한국어 접근성·판본 희소성 때문에 A급 한글화 후보일 수 있습니다. 파일을 실제 분석하지 않은 게임은 기술 난이도를 `미확인`으로 둡니다.

## 한글패치 표기 원칙

`확인 못함` 또는 `공개적으로 확인되지 않음`은 현재 공개 배포 중인 PSP 한국어 패치를 조사했지만 찾지 못했다는 뜻이며, 비공개 패치까지 포함해 절대로 존재하지 않는다는 의미는 아닙니다.

공식 한국어판과 유저 한글패치는 반드시 구분합니다.

## 게임별 문서 양식

PSP 후보도 [`../../templates/game-entry-template.md`](../../templates/game-entry-template.md)를 기준으로 다음 내용을 포함합니다.

- 영어/로마자 제목과 통용 한글 제목
- 한눈에 보기
- 스포일러 최소 시놉시스
- 왜 발굴할 만한가
- 장점 / 단점 / 외부 평가
- 한국어화 상태
- 원작·이식·확장판 관계와 플랫폼별 차이
- 한글화 가치와 우선도
- 기술 난이도 표
- 대표 스크린샷
- 한줄평 / 참고 자료

게임 상세 문서는 `platforms/psp/games/<slug>.md`에 저장합니다.
