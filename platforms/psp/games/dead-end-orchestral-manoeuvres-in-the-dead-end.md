# Dead End: Orchestral Manoeuvres in the Dead End (데드엔드)

## 2026-10-12 재평가 및 한글패치 조사 보강

> **작품성 3.5/5 · 리뷰 종합 7.1/10 유지 · 한글화 우선도 B 유지 · 기술 난이도 미확인.** 본작은 일반적인 선택지형 노벨이 아니라, **세 자리 숫자 파라그래프·조운트(Jaunt) 직접 이동·주사위 판정·숫자 퍼즐이 본문 내용과 연결되는 게임북**이다. 현재 검색 범위에서 직접 이용 가능한 공식 한국어판·공개 PSP 한국어 패치를 확인하지 못했으며 현대 기종 직접 이식도 확인되지 않는다. **미발견은 절대적인 부재 증명이 아니다.**

### 1. 판본·제품 구성: 한정판이 추가 시나리오판은 아님

- **실제 발매일 2011-09-29.** 초기 예고의 2011-09-01은 최종 발매일이 아니다. 2011-08-11 연기가 공지됐고 2011-08-24에 새 날짜가 확정됐다. [전격온라인 연기 안내](https://dengekionline.com/elem/000/000/393/393874/) · [4Gamer 최종 발매일 보도](https://www.4gamer.net/games/132/G013226/20110824002/) · [발매 당일 기사](https://dengekionline.com/elem/000/000/411/411327/).
- **UMD 일반판 7,140엔 / 한정판 8,190엔(출시 당시 세금 포함).** 한정판에는 **설정 원화집(팬북)**이 포함된다. 초기 캐릭터 디자인·무기 디자인·제작자 코멘트를 수록한 인쇄 특전이며 **추가 게임 시나리오·별도 UMD가 확인된 것은 아니다**. 이 수치는 출시 가격이고 2026년 현재 거래가격이 아니다. [Famitsu 한정판 특전](https://www.famitsu.com/news/201108/25048960.html), [4Gamer 2011-08-24 발표](https://www.4gamer.net/games/132/G013226/20110824002/).
- **PSP 다운로드 개시 2011-12-01**은 동일 작품의 배포 경로이며 **추가 에피소드/수정판으로 판정할 근거가 없다**. 다운로드 SKU·내용 차이·현재 판매 가능 여부는 미확인이다. [당시 다운로드 안내](https://www.4gamer.net/games/108/G010839/20111201019/).
- **관련 게임과 직접 이식 구분:** 개발사 테크스트。(Wizard Soft)는 PSP 《Second Novel ~그녀의 여름, 15분의 기억~》을 담당했고, 시나리오의 오츠키 료키(大槻涼樹)와 원화의 vanilla는 PC 《蠅声の王》에서도 활동했다. 이는 **창작진·형식의 연관성**이지 《데드엔드》의 PC판·후속 이식작 존재를 뜻하지 않는다. [전격온라인 주요 제작진 소개](https://dengekionline.com/elem/000/000/364/364196/).

### 2. 게임북의 실제 장점과 구조상 약점

| 검증한 요소 | 평가와 근거 | 한글화에 미치는 영향 |
|---|---|---|
| **파라그래프와 조운트(Jaunt)** | 모든 장면에 세 자리 숫자 ID가 있고, 정해진 선택지 외에 허용된 ID로 직접 이동하여 숨겨진 장면·퍼즐을 찾는다. [개발사 제공 시스템 설명](https://www.gamer.ne.jp/news/201104280005/) | 원문 순서를 스토리 순서로 취급하면 안 됨. **숫자 ID와 본문 속 참조·지도·기록 연결**을 보존해야 함 |
| **수치·아이템 기반 숫자 퍼즐** | 공식 예시는 아이템에서 발견한 숫자와 다른 장면의 힌트를 산술적으로 결합해 다음 번호를 찾게 한다. **퍼즐 정답을 문서에 공개하지 않음.** [시스템·원문 공식 예시](https://www.gamer.ne.jp/news/201104280005/) | 번역문에 숫자, 연산 지시, 힌트 방향, 대응 ID가 일관된지 검사 |
| **주사위·결과 변경** | 전투의 생명/공격/방어 수치, 함정의 성공 판정 외에 Advanced 모드에서 재시도·결과 변경이 가능하다. [Famitsu 4인 리뷰](https://www.famitsu.com/game/title/21040/reviews) | 일반·Advanced 각 모드에서 한글 UI와 판정/복귀 동작 확인 |
| **실제 장편 몰입감** | [2011-11-08 개인 완료평](https://akaheki.blog50.fc2.com/blog-entry-1211.html)은 캐릭터·배경 설명·서사, 선택 즉시 되돌리기를 긍정하며 12시간 완주를 보고 | 분기별 앞뒤 문맥과 설정 용어·인물 관계를 보존하고 12시간을 전체 검수 시간으로 오용하지 않음 |
| **분기와 엔딩 수의 구분** | 같은 완료평은 **다양한 경유 경로가 있지만 이야기의 귀결은 기본적으로 단일**이라고 지적한다. 다중 엔딩 작품으로 소개하는 것은 부정확 | **게임오버·중간 이동·숨은 파라그래프**를 별도 경로로 기록. 엔딩 수를 추정하지 않음 |
| **완주 후 보너스** | 완료평 1명은 **무한 던전과 CG·음악 감상 메뉴 해금**을 기록하고, 무한 던전은 중단 불가·성장 보상의 부족을 단점으로 들었다 | 본편 한글화만으로 완료 판정하지 말고 보너스 UI·해금·무한 던전도 검수 목록에 포함. 단일 후기 증거임을 명시 |
| **이력과 전투 밸런스** | Famitsu는 장면 번호만 보이는 기록, 썸네일·책갈피 부재를 지적. 개인 완료평은 후반 강력한 기술로 전투 전략이 단조로워진다고 평가 | 편의성 한계를 작품성 판단에 반영하되 검수 시 원본 결함과 패치 결함을 구분 |

**리뷰 교차 검증:** [Famitsu](https://www.famitsu.com/game/title/21040/reviews) **7+7+7+7=28/40**은 PSP판 크로스리뷰 4명에 대한 점수다. [개인 완료평](https://akaheki.blog50.fc2.com/blog-entry-1211.html)의 개인 8·일반 7은 **한 작성자의 두 기준**으로 중복 세지 않는다. 유료 구매자 전체의 객관적 합의로 확대하지 않는다.

### 3. 한국어판 존재 여부와 기술 조사 우선순위

- **2026-10-12 공개 검색 범위에서 일본 PSP판의 공식 한국어판 및 독립적으로 이용 가능한 공개 한국어 패치를 확인하지 못했다.** 영어 번역·다른 지역판도 근거 없이 만들어 적지 않는다. 《Death end re;Quest》나 다른 제목의 《Dead End》는 **서로 다른 작품**이므로 한국어화 증거로 사용하지 않는다.
- **이미지 리소스 선행 자료:** [The Spriters Resource의 이 PSP 게임 항목](https://www.spriters-resource.com/psp/deadendorchestralmanoeuvresinthedeadend/)에는 현재 **17개 자산 묶음(인물 14, 배경·이벤트·아이템 3)**이 등록돼 있다. 이는 이미지 추출 사례의 존재만 뒷받침하며 **실제 ISO 압축 형식·텍스트 인코딩·폰트·이미지 역삽입 성공을 입증하지 않는다**.
- **첫 번째 실험(파일 조사):** 소장 PSP UMD **ULJM-05907** 또는 검증된 다운로드판의 원본 해시·파일목록을 고정하고, 읽기 전용으로 텍스트/화자/아이템/지도/수치UI/스크립트 분모를 작성한다.
- **두 번째 실험(파라그래프 정합성):** 모든 세 자리 ID를 안정적인 키로 유지한 **번호→본문→선택지→조운트→퍼즐 힌트** 그래프를 만들고, 미발견·도달 불가 ID와 숫자 문자열이 번역으로 변형된 지점을 검사한다. 숫자 ID와 연산 결과는 임의 현지화하지 않는다.
- **세 번째 실험(한글 출력):** 시험 복사본에서 대사 1개, 선택지 1개, 수치/아이템 1개를 바꿔 **글꼴·개행·포인터·번호이동·세이브/로드·주사위 결과**를 확인한다. 실제 한글 표시 성공이나 무수정 재삽입 성공은 원본 파일 분석 전까지 미확인으로 둔다.
- **네 번째 실험(자동 검수):** 스토리 본편 통과와 별도로 **선택지·조운트·숫자 퍼즐·전투 성공/실패·Advanced 조작·숨은 장면·엔딩 후 보너스**를 기록한다. 단순 대사 자동 스킵만으로 전체 게임 검수 완료가 되지 않는다.

**결론:** 2026-10-08의 기존 **3.5/5·B**를 유지한다. 저해상도·자료 희소성만으로 감점하거나 올리지 않으며, 새로 확인한 한정판 팬북/단일 서사 구조/본편 후 보너스/숫자 퍼즐 결합과 무검증 한글화 기술을 구분해 기록한다.

## 스포일러 최소 시놉시스

고교생 제쿠토가 흡혈귀에 대응하는 조직 ‘데드엔드’의 활동에 휘말린다. 현대 오컬트 이야기를 읽고 선택하는 과정에 주사위와 탐색을 결합한 작품이다. [출시 소개](https://mantan-web.jp/article/20110929dog00m200018000c.html)

## 게임 구조 / 진행 구조

번호가 붙은 파라그래프를 읽으며 선택지나 직접 번호 이동으로 진행한다. Jaunt를 사용해 허용된 번호로 이동하고, 수치·아이템·주사위로 전투와 탐색을 수행한다. 규칙대로 진행하는 방식 외에 판정을 다시 시도하는 방식도 마련돼 있어 다른 선택을 시험하기 편하다. 특정 번호나 퍼즐 해답은 기재하지 않는다. [시스템 발표](https://www.4gamer.net/games/132/G013226/20110427132/)

## 왜 발굴할 만한가

특이한 형식 자체보다 빠른 재시도와 직접 탐색이 읽는 재미에 기여한다는 실제 평가가 중요하다. 독창성과 지속적인 전투·반복 구성의 완성도는 별도로 판단했다.

## 장점

- Famitsu 필자들은 재시도 편의와 음향·영상·퍼즐의 결합을 긍정했다.
- 개인 완료평은 지도와 공간 묘사, 주사위 전투에서 RPG·테이블톱에 가까운 재미를 얻었다고 설명한다.
- 같은 완료자는 인물에 대한 호감도 장점으로 꼽았다. 소재의 특이함만 칭찬한 것은 아니다.

## 단점

- Famitsu 4명 중 2명은 숫자 이력에서 장면을 구별하기 어렵거나 썸네일·책갈피가 아쉽다고 지적했다.
- 독자가 수치 규칙을 이해해야 해 형식의 진입 부담이 있다.
- 개인 완료평은 전투 전략의 편중, 탐색의 번거로움과 추가 플레이 동기가 아쉽다고 평가한다. 이 리뷰에서는 다양한 도중 분기에도 서사 결말이 대체로 단일하며, 클리어 후 무한 던전은 중단할 수 없다는 지적도 있다. 장면 스포일러와 구체 수치는 쓰지 않는다.

## 한국어화 상태

2026-10-12 공개 검색 범위에서 PSP 공식 한국어판·공개 완역/부분/기계번역 패치와 확인 가능한 진행·중단 프로젝트를 찾지 못했다. PC·Vita·Switch·Steam의 동일 작품 후발 한국어 대안도 미확인이다.

영문 전체 제목, 일본어 원제, 데드엔드·데드 엔드와 PSP·한국어·한글패치·Korean patch를 조합했다. 일반 ROM 목록의 반복 문구와 《Dead End 99%》 같은 다른 작품은 증거에서 제외했다. 비공개 작업의 부존재를 보장하는 결과는 아니다.

## 원작 / 이식 / 확장판 관계

PSP용으로 발표·발매된 작품이다. PSP 《Second Novel》 제작사인 테크스트。(Wizard Soft)가 개발했고, PC 《蠅声の王》의 시나리오 작가·원화가가 합류했으나, 두 작품이 **동일 작품의 서로 다른 판본이라는 근거는 없다**. [2011-12-01 다운로드 판매](https://www.4gamer.net/games/108/G010839/20111201019/)는 같은 PSP 작품의 유통이다. 현대 직접 이식은 조사 범위에서 미확인이다.

PSP판을 기준으로 소장 UMD 또는 이미 이용 가능한 다운로드판을 확인한다. 과거 배포 공지가 지금 신규 구매 가능함을 보장하지는 않는다. 다운로드판이 더 안정적이라고 검증한 것도 아니다.
