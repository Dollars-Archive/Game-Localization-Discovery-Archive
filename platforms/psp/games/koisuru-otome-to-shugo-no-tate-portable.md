## 스포일러 최소 시놉시스

경비회사 **AIGIS**의 특수요인호위과 소속 신입 에이전트 **키사라기 슈지**에게 새로운 단독 임무가 떨어진다. 임무 내용은 전 기숙사제 명문 여학교 **세인트 테레지아 학원**에 여학생으로 위장 잠입해, 정체불명의 위협으로부터 호위 대상을 보호하는 것.

작고 중성적인 외모 때문에 강제로 **야마다 타에코**라는 여학생 신분을 부여받은 슈지는 자신의 성별과 에이전트 신분을 숨긴 채 학원 생활을 시작한다. 겉으로는 아가씨 학교의 일상과 러브코미디가 이어지지만, 뒤에서는 다른 경호원과 적대 에이전트가 뒤섞이며 각 히로인 루트가 실제 호위 임무와 전투로 연결된다.

## 게임 구조 / 루트 구조

- 선택지 중심의 비주얼 노벨형 연애 ADV다.
- PS2/PSP판의 공략 대상은 **총 7명**으로, PC 원작의 주요 히로인에 **아야노코지 와카나 / 나카니시 리오** 2명이 추가됐다.
- 각 히로인 루트는 기본적으로 학원 일상 → 호위 대상과의 관계 변화 → 위협 발생 → 경호·전투 → 엔딩으로 이어진다.
- 주인공 **키사라기 슈지 / 야마다 타에코**는 PS2/PSP판에서 **쿠기미야 리에의 풀보이스**가 적용됐다.
- PC판에서 콘솔 이식될 때 신규 시나리오가 대폭 가필·수정되고, 추가 히로인에 맞춘 다수의 신규 CG와 SD 컷인 연출이 더해졌다.
- PS2판에는 7히로인 각각의 엔딩곡과 신규 OP가 들어갔고 PSP판도 이를 그대로 수록한다.
- **PSP판 자체의 핵심 차이는 PS2판 콘텐츠의 16:9 화면 대응과 휴대기 이식**이며, PSP 독자 신규 루트는 확인하지 못했다.

## 왜 발굴할 만한가

- 단순 학원 연애물이 아니라 **여장 잠입 + 전문 경호원 + 비밀 신분 + 실제 전투**를 한 작품 안에 묶은 명확한 개성이 있다.
- 주인공이 수동적인 관찰자가 아니라 임무 수행 능력과 전투력을 가진 프로 에이전트라, 히로인 보호 과정이 서사 중심에 놓인다.
- PS2/PSP 콘솔판은 원작보다 **2명의 공략 히로인, 주인공 풀보이스, 신규 시나리오와 CG**가 추가된 확장판 계열이다.
- 현대 Re:boot는 그래픽과 일부 시나리오를 새로 손봤지만, 공식 캐릭터 구성을 보면 PSP/PS2 추가 히로인인 와카나와 리오는 메인 히로인 목록에서 빠져 있다.
- 따라서 **구 콘솔판 7히로인 구성과 쿠기미야 리에 주인공 보이스를 보존하는 판본 가치**가 지금도 남는다.
- 다만 PSP판은 PS2판에서 스토리 콘텐츠가 더 늘어난 판이 아니어서, 한글화 프로젝트 관점에서는 PS2판과의 중복성이 크다.

## 장점

- **주인공 캐릭터가 강하다.** 여장을 싫어하는 남성 경호원이 실제 임무 능력으로 히로인을 지킨다는 설정이 코미디와 액션 양쪽에서 작동한다.
- 학원 러브코미디와 경호·암살자·비밀 조직 요소가 결합되어 일반적인 학원 연애 ADV보다 사건 밀도가 높다.
- 콘솔판 추가 히로인 2명으로 원작보다 공략 폭이 넓고, 주인공까지 풀보이스라 캐릭터극의 몰입도가 높다.
- 2024년 PSP판 완주 후기에서도 긴장감 때문에 계속 읽게 됐고, 보디가드 주인공의 멋과 주인공 음성을 강점으로 꼽았다.
- 2010년 전격온라인 독자 설문에서는 여장 주인공을 ‘모에’보다 **‘불타는 경호 액션’ 방향으로 다룬 작품**이라는 점을 높게 평가한 의견이 실렸다.
- PSP는 PS2판과 같은 7히로인 확장 콘텐츠를 휴대기에서 즐길 수 있고 화면이 16:9에 맞게 조정됐다.

## 단점

- **루트 구조가 반복적이라는 지적이 강하다.** PSP 완주 리뷰에서는 대부분 ‘지키는 과정에서 사랑에 빠지고 사건을 해결한다’는 유사한 흐름이라고 평가했다.
- 개별 루트가 대략 1~3시간 수준으로 짧아, 중요한 갈등이나 주제가 빠르게 해결되어 깊이가 부족하다는 비판이 있다.
- 주인공 자신의 내면 변화보다는 히로인을 구하는 구조가 중심이라 장편 서사로서의 층위는 얕은 편이다.
- GameFAQs PSP 직접 평가는 **2.25/5, 8표**로 상당히 낮다. 표본은 작지만 무시하기 어려운 약점이다.
- 2021년 PSP 완주 리뷰는 캐릭터 게임으로는 즐겁지만 전개가 원패턴이라고 평가하며 **75/100**을 부여했다.
- PSP판은 PS2판의 실질적 휴대기 이식이어서 독자 시나리오 가치가 낮다.
- 2020년 Re:boot에 비하면 해상도·음질·UI가 오래되었고, PSP판을 다시 플레이한 후기에서도 화질과 음질의 노후화가 크게 지적됐다.

## 플레이타임

- GameFAQs PSP판: **30시간 / 2표본**.
- PSP 완주 리뷰: 공통 루트 약 **6시간**, 7개 개별 루트 각 **1~3시간**, 전체 약 **20시간 전후**.
- 독서 속도와 스킵 사용에 따라 편차가 크며, 7히로인 전 루트 기준으로는 20~30시간대를 참고 범위로 보는 편이 안전하다.
- 한글화 검수에서는 공통부 + 7루트 + 다수 배드엔딩 + 개별 엔딩곡·신규 CG까지 확인해야 한다.

## 한국어화 상태

- 공식 PSP 한국어판: **2026-09-18 기준 확인되지 않음**.
- 공개 PSP 유저 한글패치: **2026-09-18 기준 공개적으로 확인되지 않음**.
- **PS2판 공개 한국어 패치 1.0.1이 2026-08-14 기준 RetroDB에 등록**되어 있다.
- 국내 비주얼노벨 커뮤니티에서도 PS2판의 한글패치 적용 기록과 배포 출처 기록이 확인된다.
- PSP판은 PS2판 기반이지만, **PS2 패치를 PSP에 그대로 적용할 수 있다고 가정하지 않는다.**
- PSP판과 동일한 7히로인 콘솔 콘텐츠를 한국어로 경험할 수 있는 PS2 대안이 존재하므로 PSP 자체의 한글화 우선도는 낮아진다.

## 원작 / 이식 / 확장판 관계

- **2007-06-29 Windows 「恋する乙女と守護の楯 The code name is “SHIELD-9”」**: AXL R18 원작.
- **2008-11-20 PS2 「恋する乙女と守護の楯 -The shield of AIGIS-」**: 전연령 확장 이식. 와카나·리오 2히로인 추가, 주인공 풀보이스, 신규 시나리오·CG·OP·엔딩곡 추가.
- **2010-07-29 PSP 「恋する乙女と守護の楯 Portable」**: PS2판 기반 휴대기 이식. 16:9 대응, PSP용 패키지 비주얼.
- **2011-12-01 PSP PS Store DL판**: 다운로드 판매 개시.
- **2016 Windows 「恋する乙女と守護の楯 ～薔薇の聖母～」**: 후속작.
- **2019 PS4 / Vita / Switch 「薔薇の聖母」**: 후속작 콘솔 이식.
- **2020 Windows / PS4 / Switch 「Re:boot The "SHIELD-9"」**: 원작을 새 그래픽·가필 시나리오로 다시 만든 리메이크 계열. 공식 콘솔판 메인 히로인 구성에는 PS2/PSP 추가 히로인 2명이 보이지 않는다.
- **2021 Windows 「Re:boot Plus」**: Re:boot 기반 성인판 추가 요소.

## 현재 추천 버전

목적별로 추천 판본이 갈린다.

- **7히로인 + 주인공 풀보이스 + 휴대성:** PSP Portable.
- **같은 7히로인 콘솔 콘텐츠를 공개 한국어 패치로 플레이:** PS2 「The shield of AIGIS」.
- **현대 해상도·UI와 새 그래픽:** PS4/Switch 「Re:boot The "SHIELD-9"」.
- Re:boot는 PSP/PS2 콘솔판 추가 히로인 2명을 그대로 보존한 단순 상위호환으로 보기 어렵다.

## 한글화 후보 평가

### 한글화 가치

- 작품성 / 희소성: **중간 이상**. 여장 잠입과 보디가드 액션을 결합한 캐릭터 ADV로 개성이 뚜렷하다.
- 한국어 접근성: **중간**. PSP 직접 패치는 확인하지 못했지만 동일 스토리 콘텐츠를 가진 PS2판 공개 한국어 패치가 존재한다.
- PSP 독자 가치: **낮음~중간**. 휴대성과 16:9 화면은 장점이지만 PS2판에서 추가된 스토리보다 더 늘어난 시나리오는 확인되지 않는다.
- 현대 대안: Re:boot가 있으나 PSP/PS2의 2명 추가 히로인을 완전히 대체하지는 않는다.
- 한글화 우선도: **C**.
- 판단 근거: PSP판 자체를 보존할 이유는 있지만, **이미 PS2판 한국어 패치가 있고 PSP 독자 시나리오가 거의 없다는 점** 때문에 실제 프로젝트 우선순위는 낮다.
