## 스포일러 최소 시놉시스

여신 크류네아가 다스리는 세계에서 하늘의 대신전이 지상으로 추락한 뒤, 사람들은 그 안에 있을 여신에게 자신의 소원을 이루어 달라고 빌기 위해 거대한 생체 미궁 `티탄`에 도전한다.

주인공 **류가**는 전설적인 용족 우로보로스의 마지막 생존자다. 몸에서 떨어지지 않는 `우로보로스의 반지`와 종족이 짊어진 파멸적 운명에서 벗어나기 위해 대신전으로 향하고, 그곳에서 기억을 잃은 백색의 무녀 **소피아**와 강한 의지를 지닌 흑색의 검사 **힐다**를 만난다. 세 사람은 서로 다른 소원을 품은 채 티탄 깊숙한 곳을 향한다.

## 게임 구조 / 루트 구조

- 전작 `UnchainBlades ReXX`의 세계와 핵심 시스템을 잇는 **정식 후속 3D 던전 RPG**다.
- 1인칭 시점으로 거대한 티탄 내부를 탐색하고 랜덤 인카운터식 턴제 전투를 반복한다. 맵 완성, 보물 탐색, 소재 수집, 장비 합성, 의뢰와 육성이 긴 플레이타임의 중심이다.
- 특정 적을 쓰러뜨리거나 조건을 맞추면 `Unchain`을 시도할 수 있고 성공한 몬스터는 **Follower**가 된다. 마스터 캐릭터 한 명은 조건에 따라 최대 4명의 팔로워를 장착해 속성·지원·추가 공격·스킬 조건을 구성한다.
- 캐릭터 성장에는 스킬 맵이 사용되며, 팔로워가 지닌 여러 `Anima` 조합이 고급 스킬 운용과 연결된다.
- 전작 계열 Burst에 더해 두 마스터가 힘을 합치는 **Ultimate Burst**와 동료 관계를 활용하는 요소가 추가됐다.
- 초반 세 장은 류가·소피아·힐다가 각각 다른 티탄을 공략하는 병렬 구조로 진행되고, 이후 파티와 큰 줄기가 합쳐진다. 이 구조 때문에 비슷한 저레벨 육성을 세 번 반복한다는 비판도 있다.
- 전작 세계관과 사건을 이어가므로 전작을 알면 설정 이해에 유리하지만, 주인공과 중심 인물은 새로 구성됐다.

## 왜 발굴할 만한가

- PSP 말기의 보기 드문 **정통 1인칭 던전 RPG 대작급 볼륨**으로, 단순 캐릭터 상품이 아니라 탐색·전투·몬스터 수집과 육성을 중심에 둔 작품이다.
- 전격온라인의 PSP 사전 플레이는 58시간 이상 진행하고도 아직 끝을 보지 못할 만큼 볼륨이 크다고 설명하면서, 레벨업·보물·맵 100% 탐색이 주는 정통 DRPG의 재미를 강하게 평가했다.
- GameFAQs PSP 사용자 평가는 **4.08/5, 25표**로 높고, 난도 평가는 **Tough, 23표**다. 장르 팬에게는 장시간 파고들 만한 게임이라는 신호가 분명하다.
- 반면 RPGamer의 동시기 3DS판 Import Retroview는 **2/5**를 주며 지나치게 긴 던전, 느슨한 스토리 배치, 비효율적인 서브시스템을 강하게 비판했다. 즉 장점과 약점이 선명한 작품이다.
- 전작은 XSEED가 영어화했지만 EXXiV는 공식 영문판으로 이어지지 않았고, 현대 플랫폼 직접 이식도 2026-09-17 조사에서 확인하지 못했다.
- 무엇보다 PSP판에는 과거 **영어 부분 번역 프로젝트와 실제 재삽입 기록**이 남아 있다. 아이템·스킬·퀘스트를 100% 번역한 V1 xdelta 패치, UTF-8 텍스트, VWF, 데이터 파일 구조에 대한 기술 메모가 공개되어 있어 한글화 기술 조사 출발점이 좋다.

## 장점

- `Unchain → Follower 편성 → Anima 조합 → 스킬·추가공격`으로 이어지는 육성 루프가 독특하다. 단순 몬스터 수집이 아니라 전투 빌드의 핵심 자원으로 연결된다.
- 전격온라인은 전작보다 편의성과 밸런스가 확실히 개선됐다고 평가했으며, 특히 팔로워 운용이 전보다 편해진 점을 강조했다.
- Famitsu의 동시 발매 3DS판 리뷰는 **7·7·8·7, 29/40**으로, 팔로워 수집과 조합, 연계 필살기, 의뢰·합성·스킬 맵 등 풍부한 육성 요소를 긍정적으로 봤다.
- GameFAQs PSP 사용자 25명의 평균이 4.08/5로 장르 팬 반응은 상당히 좋다.
- 서로 다른 유명 일러스트레이터 15명이 캐릭터 디자인에 참여하고, 테마 음악에 우에마츠 노부오, BGM에 EARTHBOUND PAPAS, 주제가에 미즈키 나나가 참여해 제작진 개성이 강하다.
- 대형 보스는 다수 부위를 노리는 전투로 변주되고, 장시간 탐색 중 장비·팔로워·스킬 조합을 계속 갱신하는 재미가 있다.

## 단점

- **던전이 지나치게 길다.** RPGamer는 평균적인 티탄 하나가 10~15시간 단위로 늘어질 수 있고, 전체 플레이가 80~90시간 이상으로 이어질 수 있다고 비판했다.
- 초반 3개 파트가 비슷한 저레벨 구간을 서로 다른 파티로 다시 육성하는 구조라 반복감이 크다.
- 난도가 높고 자원 압박이 강하다. GameFAQs 난도 평균도 `Tough`이며, 장비 가격·MP 관리·합성 소재와 후반 난도 급등이 부담이 될 수 있다.
- 팔로워·Anima·스킬맵·합성·대형 인벤토리 등 시스템은 깊지만 정리와 UI 편의가 충분히 따라오지 못한다는 평가가 있다.
- 이야기의 출발점과 세계관은 매력적이지만, 긴 던전 사이에 이벤트가 드문드문 배치되어 서사 템포가 끊긴다는 비판이 강하다.
- Famitsu는 전투 속도를 바꿀 수 없는 점과 많은 전문용어·정보량을 약점으로 지적했다.
- 장시간 RPG이므로 한국어화 후 **전체 시나리오·퀘스트·팔로워·장비·합성·후반 난도 구간을 실제 플레이로 검수하는 비용**이 매우 크다.

전투·육성 기반의 DRPG로서는 확실한 개성과 깊이가 있고 PSP 사용자 반응도 높지만, 장시간 반복 구조와 UX, 서사 페이싱의 약점이 너무 뚜렷해 **4.0 우수작으로 올리기보다는 3.5 후보**가 적절하다.

## 플레이타임

- GameFAQs PSP 통계는 **평균 55.2시간, 15명**이며 60시간 제출이 33.33%, 80시간 이상이 26.67%다.
- 전격온라인 기자는 출시 전 PSP판을 **58시간 이상** 플레이하고도 클리어하지 못했다고 기록했다.
- RPGamer의 3DS Import Retroview는 완료 시간을 **80시간 이상**으로 표시하고 본문에서는 90시간대 플레이를 언급한다.
- 한글화 프로젝트 검수량은 메인 스토리만이 아니라 초반 3개 파티 구간, 5개 주요 티탄과 기타 던전, 의뢰, 아이템·스킬·합성, 수많은 팔로워 설명까지 포함해야 한다.

## 한국어화 상태

- 공식 한국어판: **확인되지 않음**.
- 공개 PSP 한국어 패치: **2026-09-17 기준 공개적으로 확인되지 않음**.

## 원작·이식·확장판 관계

- **2011 PSP / 3DS `UnchainBlades ReXX`:** 전작. 북미에서는 XSEED가 `Unchained Blades`로 공식 영어화했다.
- **2012 PSP / 3DS `UnchainBlades EXXiV`:** 이번 등록 대상. 신주인공 류가를 중심으로 전작 세계관과 Unchain·Follower 시스템을 계승하고 편의·육성 요소를 보강한 정식 후속작.
- PSP와 3DS는 **2012-11-29 동시 발매**다.
- 3DS판은 공식 자료에서 **입체영상 지원**이 확인된다.
- EXXiV에서 PSP와 3DS 사이의 시나리오·퀘스트·캐릭터 같은 실질 콘텐츠 차이는 이번 조사에서 명확히 확인하지 못했다.
- 2026-09-17 기준 EXXiV의 Switch·Steam·현행 콘솔 직접 이식이나 리마스터는 확인하지 못했다.

- **한글화 프로젝트 대상:** PSP판. 기존 번역 프로젝트가 `NPJH-50648` 계열을 직접 다뤘고 UTF-8·VWF·데이터 파일·xdelta에 관한 실증 자료가 남아 있어 기술 조사 비용을 줄일 수 있다.
- **순수 일본어 원본 플레이:** PSP와 3DS의 콘텐츠 우열은 보류. 입체영상이 중요하면 3DS, 기존 번역·해킹 자료와 PSP 에뮬 검증을 활용하려면 PSP가 유리하다.

- 영어 접근성: 공식 영문판은 없고, PSP 팬 프로젝트는 아이템·스킬·퀘스트 중심의 부분 번역 상태다.
- 한글화 우선도: **B**.
- 판단 근거: PSP 해킹 자료가 비교적 구체적으로 남아 있는 점은 큰 장점이지만, 55시간 이상급 본편과 막대한 시스템 텍스트·후반 검수량 때문에 즉시 A급으로 올리기보다 실제 파일 구조와 한글 폰트부터 검증할 가치가 있다.

### 기술 난이도

| 항목 | 평가 | 근거 |
|---|---|---|
| 예상 텍스트량 | 많음 | 55시간 이상급 DRPG이며 메인 스토리 외에 아이템·스킬·퀘스트·몬스터·팔로워·합성·시스템 텍스트가 광범위 |
| 텍스트 추출 | **부분 확인** | GBAtemp 프로젝트에서 `data_message_text` / `data_msg_txt.dat`와 추출된 `.kdb.txt`·`.kbd.txt` 계열 파일을 실제로 다룸 |
| 텍스트 재삽입 | **부분 확인** | 아이템·스킬·퀘스트 번역의 재삽입과 게임 내 표시 성공 사례가 있으며 V1 패치까지 공개. 본편 스크립트는 별도 도구 필요 기록 |
| 폰트 작업 | **부분 확인 / 한글 미확인** | 기존 해커가 VWF가 이미 존재하고 텍스트가 UTF-8이라고 확인. 그러나 한글 글리프 수록·폰트 아틀라스·폭 정보는 미확인 |
| UI 이미지 / 아틀라스 | **추가 분석 필요** | 프로젝트에서 `.tpk` 그래픽 계열 파일을 언급했고 최종 진행표에서 이미지 번역은 0% |
| 영상 자막 | 미확인 | 애니메이션·OP 등 영상 자산은 존재하지만 자막 삽입 방식은 확인하지 못함 |
| 제어문자 / 스크립트 구조 | **부분 확인** | `data_msg_txt.dat`가 UTF-8이며 본편 스크립트는 추출 후 되돌리는 전용 도구가 필요하다는 해커 기록이 있음 |
| 실행 파일 수정 | 미확인 | 부분 번역 프로젝트에서 일부 실행 파일 관련 문자열 작업 흔적은 있으나 한글화에 필요한 수정 범위는 확정할 수 없음 |
| 패치 배포 방식 | **확인** | 팬 프로젝트가 V1을 xdelta 형태로 배포한 기록이 있음 |
| 실기·에뮬 검수 | **주의 필요** | 에뮬레이터에서 재삽입 테스트가 이루어진 기록은 있으나 한글판 전체·후반부·현행 PPSSPP·실기 검수는 새로 필요 |

### 예상 한글화 난이도

**중상 · 부분 분석 근거 있음**

이 작품은 완전히 깜깜한 PSP 타이틀은 아니다. 기존 프로젝트가 **UTF-8, VWF, 텍스트 파일 위치, 부분 재삽입, xdelta 배포**까지 확인해 두었다는 점은 매우 유리하다. 반면 본편 스크립트 재삽입 도구, 한글 글리프, `.tpk` 이미지, 장시간 실플레이 검수는 아직 큰 미지수다.
