## 스포일러 최소 시놉시스

외부와 단절된 폐촌 아오사 마을에 14명의 젊은이가 납치된다. 참가자 전원의 목에는 폭탄이 설치된 목걸이가 채워져 있고, 각자에게는 A부터 K와 JOKER까지 서로 다른 번호·클리어 조건·특수기능이 들어 있는 PDA가 지급된다.

주어진 조건을 달성하지 못하거나 규칙을 위반하면 목걸이가 폭발한다. 살아남기 위해 동맹을 맺을지, 상대의 PDA와 조건을 이용할지, 배신을 감수할지 선택해야 하는 상황에서 참가자들은 서로 다른 목적과 과거를 드러낸다.

본작은 같은 14명의 인물을 서로 다른 상황과 관계로 다시 배치해 여러 평행 시나리오를 보여 주는 군상극형 데스게임이다.

## 게임 구조 / 루트 구조

- 플레이 중 선택지를 고르는 일반적인 분기형 ADV가 아니라 **선택지 없는 키네틱 노벨**에 가깝다.
- 한 에피소드를 끝내면 다음 에피소드가 차례로 해금되는 구조다.
- 기본 진행은 **Episode A: Absolute Revenge → Episode B: Bloody Rave → Episode C: Code Revise → Episode D: Decoded Real** 순으로 열린다.
- 추가 에피소드·보조 파트에서 다른 시점과 과거 사건이 보강되어 전체 관계가 완성된다.
- 같은 참가자·같은 기본 규칙을 사용하면서도 각 에피소드에서 동맹, 생존자, 갈등 구조가 크게 달라진다.
- 전작 `Secret Game -KILLER QUEEN-`을 몰라도 본작 자체는 이해할 수 있지만, 전작을 먼저 플레이하면 후반 연결부의 의미가 더 커진다.
- 추리·전투를 직접 조작하기보다, 규칙을 이용한 심리전과 인물들의 선택을 읽는 데 집중하는 작품이다.

## 왜 발굴할 만한가

이 작품의 가장 큰 가치는 **평가가 좋지 않았던 원작 `Secret Game CODE:Revise`를 사실상 다시 만든 리메이크**라는 점이다.

4Gamer와 당시 유통 자료는 리메이크 과정에서 **기존 시나리오 약 80%를 새로 쓰고, 추가 에피소드를 포함해 전체 분량을 원작의 약 2배로 확대**했다고 설명한다. 이벤트 CG도 대량 교체·추가되었고, 신규 배경·스탠딩·주제가·무비와 전 캐릭터 보이스 재녹음까지 진행됐다.

단순 확장보다 중요한 부분은 원작에서 비중이 부족했던 참가자들에게 별도의 역할과 서사를 부여하고, 여러 에피소드에서 반복적으로 다른 선택과 결과를 보여 주어 **데스게임의 룰과 군상극을 서로 맞물리게 다시 설계했다는 것**이다.

2026년 기준 Bangumi 7.3/10·233표, VNDB 계열 약 7.5점대·148표로 장기 평가도 안정적인 편이다.

## 장점

- 원작의 문제점을 직접 반영해 시나리오 대부분을 다시 쓴 대규모 리메이크다.
- 14명의 참가자마다 서로 다른 승리 조건과 PDA 특수기능이 있어 동맹·배신·정보전의 논리가 비교적 촘촘하다.
- 한 에피소드에서 비중이 적었던 캐릭터가 다른 에피소드에서는 중심으로 올라오는 군상극 구조가 강점이다.
- 복수의 평행 시나리오를 순차적으로 읽으면서 초반의 복선과 인물 관계가 뒤에서 회수되는 설계가 좋다는 완주평이 많다.
- 원작 대비 분량이 약 2배로 늘어났고, 신규·교체 CG와 무비, 보이스 재녹음 등 시청각 보강 규모도 크다.
- Bangumi 7.3/10·233표, VNDB 계열 7.5점대·148표로 비주얼 노벨 팬층에서 평가가 안정적이다.
- 2026년 Switch판 리뷰에서도 전작보다 데스게임 규칙과 긴장감이 훨씬 세련됐다는 평가가 확인된다.
- 백로그·퀵세이브·오토 등 장편 ADV에 필요한 기본 편의 기능은 갖춰져 있다.

## 단점

- 플레이어 선택지가 전혀 없어 **게임 시스템으로서의 개입감은 사실상 없다.**
- 에피소드 순서가 강제되므로 취향에 안 맞는 루트도 다음 시나리오를 위해 끝까지 읽어야 한다.
- GameFAQs PSP 사용자 평가는 `Fair` 11표로, PSP판 단독 소표본에서는 평가가 강하지 않다.
- 일부 에피소드는 특정 캐릭터가 지나치게 강하거나 주인공 측의 존재감이 약해지는 등 루트별 밸런스 차이가 있다.
- 데스게임 특성상 폭력·사망·절망적인 전개가 반복되고, 일부 캐릭터 설정은 애니메이션적으로 과장돼 호불호가 생긴다.
- 전작의 핵심 스포일러와 연결되는 요소가 있어 시리즈 전체를 즐길 계획이라면 플레이 순서를 신경 써야 한다.
- PC `BOOSTED EDITION`에는 PSP판 이후의 추가 과거 에피소드가 존재하고, Switch판은 현대 환경에서 동일 계열 본편을 더 편하게 플레이할 수 있어 PSP판의 현행성은 낮다.

## 플레이타임

GameFAQs의 PSP판 통계는 **약 13시간, 4표본**이다. 표본이 적고 어디까지 읽었는지 범위가 불명확하다.

VNDB 계열 자료는 약 **29시간, 9표본**을 제시하며, 개별 전 루트 완주평에서도 약 **20시간 전후**가 보고된다.

에피소드별 분량 차이가 크고 후반 해금 시나리오까지 모두 읽어야 전체 이야기가 닫히므로, 번역·검수 관점에서는 단일 13시간짜리 작품으로 보지 않는 편이 안전하다.

## 원작 / 이식 / 확장판 관계

- **2011 Windows — Secret Game CODE:Revise:** 원작. 두 주요 루트 중심으로 분량과 캐릭터 활용에 비판이 있었다.
- **2013 PSP — Rebellions: Secret Game 2nd Stage:** 대규모 리메이크. 시나리오 약 80% 재작성, 분량 약 2배, 신규 에피소드·CG·무비·보이스 재녹음.
- **2013 Windows — Rebellions: Secret Game 2nd Stage BOOSTED EDITION:** PSP판 역이식 확장판. PSP 시나리오에 과거 에피소드와 성인 콘텐츠 추가.
- **2015 iOS / Android — BOOSTED EDITION 전연령판:** 모바일 이식. 보이스 지원.
- **2018 Nintendo Switch — Rebellions: Secret Game 2nd Stage for Nintendo Switch:** PSP 계열 전연령판의 현대 이식. 일본어 전용. PC BOOSTED의 추가 성인·과거 에피소드는 포함되지 않는 것으로 알려져 있다.
- **2019 Windows — FLAT 작품 합본:** BOOSTED EDITION 수록 기록.

## 현재 추천 버전

**스토리의 완전성을 가장 우선한다면 Windows `BOOSTED EDITION`**이 유리하다. PSP판 리메이크 본편을 기반으로 추가 과거 에피소드가 더 들어가기 때문이다.

**전연령·현대 기기·간편한 구동을 우선한다면 2018 Nintendo Switch판**이 가장 편하다. 본편 내용은 PSP 리메이크 계열이며 별도 UMD 환경이 필요 없다.

PSP판은 대규모 리메이크가 최초로 완성된 역사적 기준판이자 휴대용 원본이라는 보존 가치가 가장 크다.
