# PS Vita 1차 심사 — Murasaki Baby 뒤부터 Z까지 최종 원장 (2026-10-06)

## 범위와 방법

대체 기준 목록인 [PS Vita 게임 목록 M–O](https://en.wikipedia.org/wiki/List_of_PlayStation_Vita_games_(M%E2%80%93O)), [P–R](https://en.wikipedia.org/wiki/List_of_PlayStation_Vita_games_(P%E2%80%93R)), [S–U](https://en.wikipedia.org/wiki/List_of_PlayStation_Vita_games_(S%E2%80%93U)), [V–Z](https://en.wikipedia.org/wiki/List_of_PlayStation_Vita_games_(V%E2%80%93Z))의 전체 순서를 따라, 9차 원장 끝의 `Murasaki Baby` 다음부터 마지막 `Zombies: The Last Survivor`까지 788개를 확인했다. Romfun 121~70페이지의 순서·페이지 구간을 재현한 결과는 아니다.

Vita판 Metacritic 목록 257개 항목과 대조해 이 788개 가운데 70/100 이상 64개를 1차 점수 관문 통과로 표시했다. Metacritic에 Vita판 점수가 없는 작품은 낮은 점수로 간주하지 않았고, 비교 가능한 Vita판 점수나 Famitsu 근거 없이 70점 통과로 올리지 않았다. 사용자 기준의 3.5/5 작품성은 외부 점수와 별도로 판단했다. 외부 점수를 아카이브 별점으로 환산하지 않았고, 4.0 이상 상위권 작품은 일반 3.5 후보에서 분리했다.

- 앞선 1~9차 원장: 24개 잠정 후보.
- 이번 누락 L 구간: 0개 추가.
- 이번 `Murasaki Baby` 이후 788개: 3개 추가.
- **대체 목록 1,732개 전체 검토 누계: 27개 잠정 후보.** 목표 약 30개를 채우려고 기준을 낮추지 않았다.
- 활성 PS Vita 목록의 27개 등록 상태와 내용은 수정하지 않았다. 이 PR은 조사 원장만 추가하며, 후보 등록이나 병합은 포함하지 않는다.
- 실제 게임 파일 분석 전까지 패치 제작 난이도는 미확인이다.

## 조사 범위 정정

앞선 9개 보고서는 파일명상 각각 “100개”라고 표기했지만, source list의 실제 제목 경계로 다시 계산하면 총 **907개**가 덮인다. 5차 경계는 99개, 7차 경계는 108개이며, 8차 종료와 9차 시작 사이의 37개가 빠져 있었다. 이번 보충분은 37+788=**825개**다. 따라서 907+825=**1,732개**로 현재 대체 목록 전체를 덮는다. 이전 PR 본문에 있던 “연속 900개” 표현은 실제 행 수를 반영하도록 바로잡는다.
