# PS Vita 1차 심사 — A–D 목록 첫 100개 (2026-10-06)

## 조사 범위와 판정 기준

이번 묶음은 Romfun 페이지 순번을 재현한 목록이 아니다. Romfun의 페이지별 목록을 안정적으로 확보하지 못해, 대체 목록인 [PS Vita 게임 목록 A–D](https://en.wikipedia.org/wiki/List_of_PlayStation_Vita_games_(A%E2%80%93D))에서 알파벳순 앞 100개를 심사했다. 범위는 `&: Sora no Mukō de Saki Masuyō ni`부터 `Attack of the Toy Tanks`까지다. 따라서 결과를 Romfun 121~120페이지 조사 결과로 해석하면 안 된다.

- 1차 점수 관문은 외부 평론가 점수 70/100 이상이다. Vita 전용 Metacritic 종합점수를 우선했고, Famitsu만 있는 경우에는 원점수(/40)를 함께 적고 40점 만점을 100점으로 환산해 관문에만 사용했다.
- 외부 점수는 아카이브 별점으로 환산하지 않는다. 아카이브 README의 작품성 평가는 별도 정성 판단이며, 3.5는 약점과 편차가 있어도 등록을 검토할 만한 기준이다. 아래 3.5 표기는 정식 평정 전 잠정 후보 수준이다.
- 공식 한국어판 또는 공개 한글패치가 Vita판이나 다른 기종의 동일 작품에 확인되면 제외했다. 공개 검색에서 패치를 찾지 못한 것은 부재의 확정 증명이 아니다.
- 아카이브의 이미 등록된 작품은 중복 후보에서 제외했다. `Ar nosurge Plus`는 기존 PS Vita 목록에 있어 재등록하지 않는다.
- 목표 약 30개는 여러 묶음 전체의 작업 목표로 유지한다. 이번 묶음에서 엄격한 관문을 통과한 수가 적더라도 기준을 낮춰 채우지 않는다.

## 별도 상위권 재검토

**Angelique Retour**는 Famitsu 10/8/10/9, 합계 37/40을 받은 작품이다. [Famitsu 점수 보도](https://www.gameblast.com.br/2015/12/famitsu-scores-08-dezembro-2015.html) 높은 외부 평론 점수와 장르 역사상 의미가 있어 4.0 초과급인지 관리자 재검토 대상으로 분리했다. 외부 37/40만으로 아카이브 별점을 4.0 이상이라고 확정하지 않으며, 현재 5개 잠정 후보 수에는 넣지 않았다. 초기 작품의 게임성이 구식으로 느껴질 수 있다는 관점도 있어 실제 아카이브 기준 검토가 필요하다. [시리즈·초기작 맥락](https://www.fangirl.eu/2008/10/31/les-jeux-de-drague-pour-filles-la-serie-des-angelique/)

## 저장소 반영 범위

이 파일은 1차 심사 원장이다. 활성 후보 표와 작품 수는 수정하지 않았다. 후보 5개는 관리자 의견과 정식 아카이브 별점 심사를 거친 뒤, 등록할 작품만 기존 게임 항목 템플릿의 상세 근거·스크린샷·기술 난이도 확인을 보완한다. 기술 난이도는 실제 파일 분석 전까지 미확인으로 둔다.
