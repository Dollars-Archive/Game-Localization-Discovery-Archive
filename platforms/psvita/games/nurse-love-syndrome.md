## 스포일러 최소 시놉시스

주인공 사와이 카오리는 어린 시절 큰 교통사고에서 목숨을 건진 경험을 계기로 간호사를 꿈꿔 왔다. 간호학교를 졸업한 뒤 고향 유리가하마 종합병원에 신입 간호사로 들어간 그녀는 실제 임상 현장에서 처음으로 환자의 고통, 죽음, 책임, 직장 내 인간관계와 맞닥뜨린다.

카오리는 환자의 통증을 덜어 주는 듯한 ‘치유의 손’을 갖고 있지만, 작품의 중심은 초능력보다 **신입 간호사가 실제 현장에서 실수하고 혼나고 배우며 성장하는 과정**에 있다.

공통 루트 이후에는 선배 간호사·수간호사·환자 등 여러 여성과의 관계가 개별 루트로 갈리며, 연애뿐 아니라 직업 윤리·질병·가족·트라우마·죽음 같은 주제를 각기 다른 각도에서 다룬다.

## 게임 구조 / 루트 구조

- **긴 공통 루트:** 초반 상당 부분은 연애보다 신입 간호사 카오리의 직업 적응과 병원 생활에 집중한다.
- **6명 중심 루트:** 하츠미·나기사·야스코·사유리·아미·마유키를 중심으로 개별 분기가 존재한다.
- **20개 이상 엔딩:** 공식 Steam 설명은 20개 이상의 엔딩을 명시한다.
- **Re:Therapy 증보:** 원작 3명 중심 구조에 야스코·아미·마유키 관련 신규 루트와 추가 후일담이 더해졌다.
- **원작 3인 후일담:** 기존 하츠미·나기사·사유리 굿엔딩 뒤의 추가 이야기가 수록된다.
- **선택지 누적형:** 초반 선택이 호감도와 루트 진입에 영향을 주며, 일부 진입 조건은 직관적이지 않다.
- **배드엔딩 비중:** 인물별 굿엔딩 외에도 어두운 결말과 분기가 많다.
- **풀보이스:** 주인공 포함 주요 인물에 일본어 음성이 수록된다.
- **스킵·저장:** 기독 텍스트 고속 스킵과 다중 세이브를 지원해 반복 회차를 보조한다.

## 왜 발굴할 만한가

본작의 가장 강한 부분은 **병원을 배경으로 했다는 설정 자체가 아니라, 실제 간호 업무를 이야기의 중심에 놓았다는 점**이다.

시나리오 담당 원 마도카와 사쿠라 사쿠라는 실제 간호 경험을 갖고 있으며, 주사·IV·사후처치·환자와의 거리·직장 내 괴롭힘·죽음을 대하는 태도처럼 일반 연애 VN에서 보기 어려운 현장 소재를 긴 공통 루트에 녹여 냈다.

Siliconera는 이 공통 루트를 ‘간호사가 된다는 것이 무엇인지’를 진지하게 다룬 성장 이야기로 높게 평가했고, oprainfall도 의료 현장 묘사의 현실성을 강점으로 꼽았다. 이 때문에 백합 연애물보다 **직업 성장 드라마**로 읽을 때 작품의 개성이 가장 잘 드러난다.

반면 개별 연애 루트는 질과 길이가 고르지 않다. 원작과 Re:Therapy에서 시기별로 추가된 콘텐츠가 한 작품 안에 겹겹이 들어가면서, 공통 루트에서 자연스럽게 이어지는 루트와 갑자기 분위기가 바뀌는 루트가 섞여 있다.

## 장점

- Steam은 2026-09-22 기준 **92% 긍정·262평가**로 장기간 높은 사용자 평가를 유지한다.
- GameGrin의 Vita 직접 리뷰는 **8/10**.
- oprainfall은 전 굿엔딩을 약 33시간 플레이한 뒤 작품의 의료 묘사와 성장 서사를 강하게 호평했다.
- Siliconera는 공통 루트의 간호사 성장·현실적 병원 소재를 작품의 핵심 강점으로 평가했다.
- 현직 간호 경험을 바탕으로 한 시나리오 덕분에 업무·환자·죽음 묘사가 구체적이다.
- 흔한 학원 연애물과 달리 21세 신입 직장인의 성장과 의료 현장을 중심에 둔다.
- 하츠미·나기사·사유리·야스코·아미·마유키의 관계가 서로 다른 병원 문제와 연결된다.
- Re:Therapy는 원작의 신규 공략 대상·신규 캐릭터·후일담을 모두 포함한다.
- 2019 리마스터는 원작의 작은 해상도·낡은 그래픽을 대폭 리파인했다.
- 서구 Vita판은 영어 현지화를 공식 제공해 작품 보존·접근성이 높다.
- 2023 이후 Steam·PS4에서 공식 한국어까지 제공돼 작품 자체의 접근성은 현재 매우 좋다.

## 단점

- Vita Metacritic은 **평론 2개뿐**이고 80점·50점으로 반응이 크게 갈린다.
- Gaming Age는 주인공과 지나치게 긴 이야기에 강한 불만을 보이며 **50/100**을 줬다.
- Siliconera도 공통 루트와 달리 연애 루트는 **길이와 완성도가 혼재**한다고 평가했다.
- Re:Therapy에서 엔딩 수가 크게 늘어나면서 일부 회차는 볼륨 팽창처럼 느껴질 수 있다.
- Vita Paradisa는 2019 리마스터가 기존 원작 그래픽은 크게 개선했지만, **2012년 Re:Therapy에서 추가된 일부 자산은 새 스타일로 완전히 갱신되지 않아 시각적 일관성이 깨진다**고 지적했다.
- 공통 루트에서 연애 루트로 진입하는 순간 분위기 전환이 다소 갑작스럽다.
- 일부 루트는 의료 성장 드라마보다 전형적인 연애·멜로드라마 비중이 커져 작품의 가장 독특한 강점을 희석한다.
- 선택지와 루트 진입 조건이 항상 직관적이지 않아 공략 의존도가 올라갈 수 있다.
- 플로차트형 재회차 지원이 없어서 20개 이상 엔딩 전수 회수는 반복 부담이 있다.
- 현재는 공식 한국어 현대판이 존재해 Vita 신규 번역 대상으로서의 필요성은 낮다.

## 현재 추천 버전

**한국어 플레이는 Steam 또는 한국 PS4판이 가장 실용적이다.**

Steam은 현재 공식 한국어·영어·일본어·중국어를 모두 지원하고, PC 접근성이 가장 좋다. PS4 한국판도 공식 한국어를 제공해 콘솔 플레이 대안이 된다.

**휴대 영어가 목적이면 Switch 또는 Vita 서구판**이 가능하다. Vita판은 2019 리마스터와 서구 공식 영어판이라는 보존 가치가 있지만, 현재 언어 접근성과 구매 편의에서는 Steam·PS4가 우위다.

- 영어 접근성: Vita 자체에 공식 영어판 존재.
- Vita 독자 콘텐츠: 없음. 같은 리마스터가 PC·Switch·PS4에 존재.
- 텍스트량: 많음. 긴 공통 루트 + 다수 루트·엔딩.
- 한글화 우선도: **C**.
- 판단 근거: 작품 자체는 발굴 가치가 충분하지만, Steam·PS4에 공식 한국어가 있고 Vita에도 공식 영어판이 있어 신규 Vita 한국어화의 실익이 매우 낮다.

### 기술 난이도

| 항목 | 평가 | 근거 |
|---|---|---|
| 예상 텍스트량 | **많음** | 긴 공통 루트 + 6명 중심 루트 + 20개 이상 엔딩 |
| 실행 엔진 단서 | **부분 확인** | Vita3K 로그의 메인 실행명이 KuroNekoScript |
| 리소스 컨테이너 | **부분 확인** | res.psarc·res_jp.psarc 로드 확인 |
| 텍스트 추출 | 미확인 | PSARC 내부 문자열 포맷·스크립트 추출 도구 미확인 |
| 텍스트 재삽입 | 미확인 | PSARC 재패킹·문자열 제약 실증 없음 |
| 폰트 작업 | **시스템 폰트 사용 일부 확인** | jpn2.pvf·jpn3.pvf 로드 확인 / 한글 렌더링 방식은 미검증 |
| UI 이미지 / 아틀라스 | 미확인 | res 계열 내부 구성 미분석 |
| 음성·BGM | 미확인 | 컨테이너 내부 구조 미분석 |
| 영상 자막 | 미확인 | 영상·자막 구조 미분석 |
| 제어문자 / 스크립트 구조 | 미확인 | 실제 명령 구조 미분석 |
| 실행 파일 수정 | 미확인 | 한글 표시를 위한 EBOOT 수정 필요 여부 미확인 |
| 패치 배포 방식 | 미확인 | Vita 한국어 rePatch 사례 확인 못함 |
| 실기·에뮬 검수 | **부분 확인** | PCSG-01275 Vita3K 실행 로그 존재 / 한국어 수정본 검증 없음 |

### 예상 한글화 난이도

**미확인에 가까운 부분 확인.**

Vita3K 실행 로그에서 본작의 메인 실행 모듈이 **KuroNekoScript**로 표시되고, res.psarc와 res_jp.psarc를 실제로 여는 것이 확인된다. 또한 Vita 시스템 폰트 jpn2.pvf, jpn3.pvf 사용 흔적도 보인다.

하지만 컨테이너 내부 스크립트 형식과 인코딩, 재패킹, 한글 폰트 사용 방식은 확인되지 않았다. 현대판 공식 한국어가 있다는 사실도 Vita용 파일 구조가 자동으로 해결된다는 뜻은 아니므로 기술 난이도는 낮음으로 단정하지 않는다.

**PS Vita / ⭐⭐⭐½☆ 3.5/5 / 🟢 후보 / 한글화 우선도 C / 기술 난이도 미확인에 가까운 부분 확인.**
