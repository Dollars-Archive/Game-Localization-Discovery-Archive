## 스포일러 최소 시놉시스

플레이어는 함대를 지휘하는 제독이 되어, 역사적 군함을 모티브로 한 수많은 '칸무스'를 수집·육성·편성하고 심해서함 세력과 전쟁을 치른다.

브라우저판과 가장 큰 차이는 게임 전체가 **유한한 턴제 전쟁**으로 다시 짜여 있다는 점이다. 전투 한 번만 잘한다고 끝나는 것이 아니라, 각 해역에 함대를 배치하고 수송선으로 자원을 확보하며, 적의 반공에 대비해 전선을 유지해야 한다. 최종적으로 심해서함의 본거지를 격파하면 엔딩에 도달하며, 일부 전력을 계승해 더 높은 난이도로 주회할 수 있다.

## 게임 구조 / 루트 구조

- **완전 턴제:** 1턴이 게임 내 1일에 해당하며, 브라우저판의 현실 시간 대기 대신 턴 경과로 입거·건조·보급 등의 시간이 처리된다.
- **전략맵:** 여러 해역에 함대를 배치·이동시키며 전선을 관리한다.
- **병참:** 연료·탄약·강재·보크사이트를 확보하기 위해 수송선을 건조하고 호위 함대를 붙이는 등 자원 흐름 자체가 핵심 게임플레이다.
- **다중 함대:** 최대 여러 함대를 서로 다른 해역에서 동시에 운용하며 공세·방어·연습·지원 역할을 나눈다.
- **전투:** 브라우저판처럼 개별 함선을 직접 조작하지는 않지만 전투 지휘 명령과 진형·장비·함대 조합으로 개입 폭이 넓어졌다.
- **적 반공:** 플레이어가 점령한 해역으로 심해서함이 역공해 오므로 단순 스테이지 순차 클리어가 아니다.
- **수집·육성:** 160명 이상 규모의 칸무스, 레벨·개장·장비·건조·드롭·임무 등의 핵심 수집 요소를 유지한다.
- **엔딩과 주회:** 최종 거점 격파 후 엔딩이 있으며, 일부 칸무스를 계승한 강한 뉴게임과 상위 난이도 도전이 가능하다.
- **난이도:** 기본 3단계에 숨겨진 상위 난이도가 더 있는 구조로 소개됐다.

자료: [4Gamer 장문 리뷰](https://www.4gamer.net/games/234/G023462/20160425019/), [GAME Watch 리뷰](https://game.watch.impress.co.jp/docs/review/743163.html), [PlayStation Blog 초반 가이드](https://blog.ja.playstation.com/2016/02/25/20160225-kancolle/).

## 왜 발굴할 만한가

`艦これ改`의 가치는 단순히 '칸코레를 Vita에서 할 수 있다'는 데 있지 않다. 브라우저판의 핵심인 수집·육성·랜덤 전투를 남겨 두면서, **실시간 서비스 게임을 유한한 오프라인 전략 시뮬레이션으로 재구성**했다는 데 있다.

특히 현실 시간 대기를 제거하고, 그 빈자리에 수송선·전략 해역·적 반공·다중 함대·엔딩과 주회를 넣었다. 4Gamer의 장문 리뷰도 브라우저판을 '병참의 게임', Vita판을 '병참과 군사행동의 게임'으로 구분한다.

완성도가 매끈한 작품은 아니다. 출시 초기 버그, 불친절한 설명, 긴 로딩, 다단계 UI, 랜덤성이 강한 전투와 전략 시스템의 충돌이 반복적으로 지적된다. 다만 두 차례 패치 뒤 안정성이 개선됐고, 독립된 전략게임으로서의 설계 차이는 명확하다.

## 장점

- 브라우저판의 실시간 대기 구조를 턴제로 바꿔 자신의 페이스로 계속 진행할 수 있다.
- 수송·보급·전선 유지·적 반공이 추가돼 함대 운영의 전략성이 크게 올라갔다.
- 여러 함대를 동시에 서로 다른 해역에 배치하는 운영이 가능하다.
- 엔딩과 주회 계승이 있어 온라인 서비스와 달리 하나의 완결된 캠페인으로 플레이할 수 있다.
- Live2D 계열의 움직이는 비서함 연출과 Vita 터치 조작을 활용한다.
- 패미통은 7/7/8/7로 평가했고, 전반적으로 수집·육성·전략 강화와 휴대성을 장점으로 들었다.
- GAME Watch는 대기시간 제거와 병렬 함대 운영으로 브라우저판과 다른 몰입감을 준다고 평가했다.
- 4Gamer는 단순 이식이 아니라 병참과 군사행동을 결합한 별도 게임으로 분석했다.
- 현재 서비스형 원작과 별개로, 서버 없이 보존 가능한 오프라인 칸코레라는 독자적 가치가 있다.

## 단점

- 출시 직후 진행과 플레이 품질에 영향을 주는 버그가 다수 보고됐고, 패치 전후 평가 차이가 크다.
- 메뉴 이동과 화면 전환이 번거롭고 로딩이 잦다는 사용자 지적이 반복된다.
- 튜토리얼과 임무·원정 조건 설명이 부족해 외부 공략 의존도가 높다.
- 전략성을 높였지만 전투 결과의 랜덤성이 여전히 커 계획과 결과의 괴리가 생길 수 있다.
- Live2D 움직임의 품질 편차와 단조로운 UI 디자인이 지적된다.
- 높은 난이도에서는 적 반공과 자원 압박이 강해 장기 운영 피로가 커진다.
- 새로운 칸무스 매력 요소나 시나리오 콘텐츠보다 시스템 재설계에 무게가 실려 있어 캐릭터 게임으로만 기대하면 신선함이 적다.
- 약 1년 만에 패키지 출하와 DL 판매가 종료돼 공식 신규 구매 접근성이 사라졌다.

## 플레이타임

정형화된 메인 스토리형 게임이 아니어서 단일 평균으로 보기 어렵다.

- 4Gamer 사용자 리뷰에는 **20~40시간, 40~60시간** 플레이 사례가 다수 보인다.
- 가격.com에는 **101시간 이상** 플레이한 사용자 리뷰가 있다.
- 현대 Bangumi 사용자 기록에는 고난도·완전 수집을 목표로 **수백 시간**까지 간 사례도 존재한다.
- 난이도, 세이브·로드 사용, 함선 수집, 고난도 주회, 전함 계승 목표에 따라 플레이타임 차이가 매우 크다.
- 한글화 검수는 전략 화면·임무·장비·함선 정보·튜토리얼·전투 UI·다수 이미지 텍스트까지 포함하므로 일반 1회 클리어보다 검수 범위가 넓다.

## 원작·이식·확장판 관계

- **브라우저판 艦隊これくしょん -艦これ- / 2013:** 온라인 서비스형 원작.
- **艦これ改 / PS Vita 2016:** 원작 시스템을 바탕으로 턴제·전략맵·반공·수송·엔딩·주회 등을 추가한 독립 오프라인 재설계판.
- **艦これ Arcade / 2016:** 세가의 아케이드판. 전투 표현과 조작 구조가 다른 별도 작품.
- **Android판:** 브라우저 서비스 계열의 모바일 접근판. 艦これ改의 포팅이 아니다.
- **후발 이식:** 艦これ改 자체의 PS4·PC·Switch 공식 이식이나 리마스터는 2026-09-21 조사 기준 확인되지 않음.
- PS Vita판은 2017년 1월 말 패키지 출하 및 DL 판매가 종료됐다.

## 현재 추천 버전

**'현재 서비스되는 칸코레의 최신 콘텐츠'가 목적이면 브라우저판이 별도 기준점**이다. 지속 서비스형이라 함선·이벤트·시스템 누적량에서 2016 Vita판과 직접 비교하기 어렵다.

반대로 **서버 없이 끝까지 완주할 수 있는 턴제 전략·병참 게임으로서의 칸코레**를 원한다면 `艦これ改`를 대체하는 공식 후발판은 확인되지 않는다. 이 목적에서는 Vita판 자체가 현재도 유일한 대상이다.

### 한글화 가치

- 작품성: **중상 / 편차 큼.** 독특한 전략 재설계는 성공했지만 기술적 마감과 UX가 약함.
- 희소성: PS Vita 독점이며 공식 판매가 2017년에 종료.
- 한국어 접근성: 공식 한국어판·공개 한국어 패치를 확인하지 못함.
- 영어 접근성: 공식 영문판 없음. WIP 팬 번역 프로젝트만 존재.
- 기존 번역 기술 자산: **매우 유용함.** 텍스트 추출·이미지·폰트·Assembly-CSharp.dll·rePatch 빌드 경로가 공개돼 있음.
- 판본 대안: 艦これ改의 턴제 전략 시스템 자체를 대체하는 공식 후발판 없음.
- 한글화 우선도: **🔥 A**.
- 판단 근거: 3.5점 작품이지만 Vita 독점성·판매 종료·한국어 대안 부재·독자 시스템·기존 리버스엔지니어링 자산까지 동시에 갖춰, 실제 파일 구조를 먼저 확인할 효율이 높다.

### 기술 난이도

| 항목 | 평가 | 근거 |
|---|---|---|
| 예상 텍스트량 | **많음** | 160명+ 함선 정보·임무·튜토리얼·전략·전투·장비·시스템 문자열 |
| 텍스트 추출 | **부분 확인** | 공개 프로젝트가 XML과 바이너리 문자열을 추출하고 `kc.po` 기반 번역 사전을 사용 |
| 텍스트 재삽입 | **부분 확인** | 공개 패처가 asset 파일과 Assembly-CSharp.dll 문자열을 교체하는 빌드 경로 제공 |
| 폰트 작업 | **중~높음 / 부분 확인** | A-OTF 계열 TTF가 asset에 있고 FontForge·PUA 다중문자 글리프 치환을 사용. 한국어 글리프 적용은 별도 검증 필요 |
| UI 이미지 / 아틀라스 | **부분 확인** | `Unity_Assets_Files`, UnityTexTool, PNG 왕복 방식의 이미지 번역 경로 공개 |
| 영상 자막 | **미확인** | 영상 자막 범위와 별도 컨테이너는 현재 자료로 확정 불가 |
| 제어문자 / 스크립트 구조 | **중~높음** | 색상 태그 수 검증, UTF-16·UTF-8 혼재, XML과 DLL 문자열이 함께 존재 |
| 실행 파일 / DLL 수정 | **필요 범위 확인** | `Assembly-CSharp.dll`의 UCS-2 LE 중심 문자열을 바이너리 수정하며 일부 UTF-8 enum도 존재 |
| 패치 배포 방식 | **확인** | PS Vita v1.00 + 공식 v1.02 패치 기준, VitaShell + rePatch 방식의 공개 설치 절차 존재 |
| 실기·에뮬 검수 | **실기 경로 확인 / 한국어 미검증** | 공개 프로젝트는 실기 Vita 적용을 전제로 함. 한국어 빌드 및 Vita3K 호환은 별도 확인 필요 |

### 예상 한글화 난이도

**중~높음 / 부분 확인.**

완전한 미지의 포맷은 아니다. 오히려 공개 번역 프로젝트 덕분에 **어디에 문자열·폰트·이미지가 있고 어떻게 rePatch로 다시 올리는지** 상당 부분 드러나 있다. 다만 긴 한글 문자열을 Vita UI에 맞추는 문제, PUA 기반 글리프 치환 방식의 한글 적용, DLL 길이 제약, 이미지 식질 범위, 방대한 시스템 검수가 남아 있어 쉬운 프로젝트는 아니다.

## 한줄평

**서비스형 수집게임의 뼈대를 턴제 병참전으로 다시 조립한 야심은 분명하고 지금도 대체판이 없지만, 버그·로딩·UI가 그 야심에 녹을 잔뜩 슬어놓은 독특한 Vita 전용 전략판.**

## 최종 판정

**PS Vita / ⭐⭐⭐½☆ 3.5/5 / 🟢 후보 / 한글화 우선도 🔥 A / 한글화 난이도 중~높음·부분 확인.**

등록선은 통과한다. 패미통 29/40과 전문 장문 리뷰들은 턴제 병참·전선 유지·다중 함대·오프라인 캠페인의 차별성을 뚜렷하게 확인한다. 반면 4Gamer 독자평 51/100·16명, 긴 로딩과 불편한 UI, 설명 부족, 출시 초기 버그 및 강한 랜덤성은 4.0을 주기 어려운 구조적 약점이다.

A급 판정은 희귀성 하나 때문이 아니다. **Vita 독점 독자 시스템 + 공식 판매 종료 + 한국어 대안 부재 + 공식 후발 이식 부재 + 실제 번역 툴체인 공개**가 동시에 성립한다. 한글화 후보 발굴 관점에서는 파일 구조 분석을 먼저 해볼 기대값이 높은 편이다.
