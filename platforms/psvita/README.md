## PS Vita 등록 운영

- 이 구역의 조사·등록 대상은 **PS Vita판**입니다. 원제·부제·시리즈 순번·실제 발매 기종을 먼저 확인하고, 다른 플랫폼 판본과 혼동하지 않습니다.
- 작품성 기준은 루트 README와 동일합니다. **독점·희소성·추가 콘텐츠·취향 적중만으로 점수를 가산하지 않으며, 평가 근거가 부족한 작품을 관성적으로 3.5점에 넣지 않습니다.** 3.0 이하 또는 판정 근거 부족은 기본 미등록입니다. 별도 사용자 승인 예외는 명시해 분리합니다.
- 공식 한국어판, 공개 PS Vita 유저 한글패치, 다른 플랫폼의 한국어판·한글패치를 구분하고 작품별 실제 조사일을 기록합니다. 조사 전에는 한국어화 상태를 단정하지 않습니다.
- PSP·PS2·PC 원작과 PS Vita 이식판, 후발 Switch·PC 등 판본의 추가·삭제 콘텐츠와 개선·열화를 비교합니다. 다른 플랫폼의 평점이나 한글패치를 PS Vita판의 것으로 옮겨 적지 않습니다.
- **발굴 추천도 / 한글화 우선도 / 기술 난이도는 별도 축**입니다. 실제 게임 파일 또는 신뢰할 만한 해당 판본 기술 분석 전에는 기술 난이도를 `미확인`으로 유지합니다.
- PS2·PSP에 이미 등록된 작품도 PS Vita판을 독립 평가합니다. 같은 PS Vita판의 지역판·재판·제목 표기 차이는 중복 확인 후 하나의 문서에서 관리합니다.
- 상세 문서는 공통 [게임 등록 양식](../../templates/game-entry-template.md)을 사용해 `games/<game-slug>.md`에 저장합니다. 등록할 때 이 목록·상세 문서·루트 집계를 함께 갱신하고 웹 목록과 상세 링크를 검증합니다.
