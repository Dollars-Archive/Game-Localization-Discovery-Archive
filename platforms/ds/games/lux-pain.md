# Lux-Pain (럭스 페인)

- 원제 — ルクス・ペイン
- 대상 — 2008년 Nintendo DS판. 일본 DS판과 북미·유럽 영어판. DS 《어나더 타임 어나더 리프》는 별개 작품.
- 발굴 추천도 — 3.5/5
- 리뷰 기반 편집 점수 — 7.1/10
- 한글화 우선도 — C

## 작품 평가

터치펜으로 잔류 사념을 찾아 인물의 감정과 사건을 추적한다. 도입부에 용어가 많고 이동 제한과 탐색 반복이 있다. 북미판에는 번역과 음성·텍스트 불일치 비판이 있어 일본판 평가와 구분했다.

## 한국어화 확인

2026-11-26 공개 자료에서 DS판 공식 한국어·공개 한글패치 미확인. 기술 난도 미확인. 작품명과 원제로 공개 배포 및 정식 발매 자료를 조사했다. 미검색·비공개 패치의 존재 여부와 실제 실행은 확인 범위 밖이다.
