# Sigma Harmonics (시그마 하모닉스)

- 원제 — シグマ ハーモニクス
- 대상 — 2008년 Nintendo DS판. 일본 DS판. 공개 영어 팬 번역 기록은 한국어 대안과 구분.
- 발굴 추천도 — 3.5/5
- 리뷰 기반 편집 점수 — 7.7/10
- 한글화 우선도 — B

## 작품 평가

단서의 순서를 맞춰 과거의 사건을 재구성하고, 추리 결과가 전투에 영향을 준다. 추리와 전투의 결합이 독특하지만 이동과 일반 전투가 반복되고 일부 추론은 납득하기 어렵다.

## 한국어화 확인

2026-11-26 공개 자료에서 DS판 공식 한국어·공개 한글패치 미확인. 기술 난도 미확인. 작품명과 원제로 공개 배포 및 정식 발매 자료를 조사했다. 미검색·비공개 패치의 존재 여부와 실제 실행은 확인 범위 밖이다.
