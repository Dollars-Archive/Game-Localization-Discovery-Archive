# BLEACH: The 3rd Phantom (블리치: 더 서드 팬텀)

- 원제 — BLEACH ザ・サード・ファントム
- 대상 — 2008년 Nintendo DS판. 일본 DS판과 서구 공식 영어판. 《블리치 DS 2nd》 격투 게임의 한글패치는 별도.
- 발굴 추천도 — 3.5/5
- 리뷰 기반 편집 점수 — 7.0/10
- 한글화 우선도 — C

## 작품 평가

원작 세계의 별도 이야기와 다양한 사신을 운용하는 격자 전투가 팬에게 매력적이다. 전투 템포가 느리고 대화 분량과 반복이 부담이 될 수 있다.

## 한국어화 확인

2026-11-26 공개 자료에서 DS판 공식 한국어·공개 한글패치 미확인. 기술 난도 미확인. 작품명과 원제로 공개 배포 및 정식 발매 자료를 조사했다. 미검색·비공개 패치의 존재 여부와 실제 실행은 확인 범위 밖이다.
