# Magical Starsign (매지컬 스타사인)

- 원제 — マジカルバケーション ５つの星がならぶとき
- 대상 — 2006년 Nintendo DS판. 일본 DS판과 북미 공식 영어판. GBA 《매지컬 베케이션》은 전작.
- 발굴 추천도 — 3.5/5
- 리뷰 기반 편집 점수 — 7.3/10
- 한글화 우선도 — C

## 작품 평가

행성의 위치와 속성이 전투에 영향을 주고 전후열에 따라 마법의 공격 범위가 달라진다. 밝은 캐릭터와 세계가 매력적이지만 잦은 무작위 전투와 평이한 줄거리가 진행을 늘어지게 한다.

## 한국어화 확인

2026-11-26 공개 자료에서 DS판 공식 한국어·공개 한글패치 미확인. 기술 난도 미확인. 작품명과 원제로 공개 배포 및 정식 발매 자료를 조사했다. 미검색·비공개 패치의 존재 여부와 실제 실행은 확인 범위 밖이다.
