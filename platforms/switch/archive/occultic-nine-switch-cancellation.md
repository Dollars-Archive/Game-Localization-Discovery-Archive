## 3. 스포일러 최소 줄거리

무대는 도쿄 **기치조지**. 고등학생이자 오컬트 기사 수집 블로그 **키리키리 바사라** 운영자인 **가몬 유타**는 인터넷의 온갖 오컬트 뉴스를 비판하거나 선정적인 기사로 엮으며 광고 수익을 꿈꾼다. 어느 날 취재 중 시체를 발견하고, 인터넷 댓글·점술·흑마술·초능력·유령·의문의 주파수가 교차하는 거대한 수수께끼에 휘말린다.

서로 연관이 없어 보였던 **아홉 인물의 삶**은 한 사건을 중심으로 연결되고, 오컬트 현상을 **과학적 해석**으로 설명하려는 시도가 이야기의 뼈대를 이룬다. 원작과 애니는 인물별 교차 시점을 활용하는 반면, **2017 게임판은 유타 시점이 중심**이라 다른 인물들의 생각과 사건 해설이 일부 단순화됐다.

**스토리 강점**
- 2010년대 블로그·트위터·생방송·댓글 문화, 괴담과 현대 과학의 접합이라는 매우 독특한 장르 구상.
- 성우·시부야/기치조지 배경의 도시괴담, 전파·초능력의 단서 등 **오컬트가 합리적으로 보이는 방식**에 대한 기대를 높임.
- 9명의 뚜렷한 캐릭터성과 여러 단서가 하나의 사건으로 모이는 세계관, 팝아트·만화적 UI가 강점.

**스토리 감점**
- 같은 내용을 이미 다룬 2016 애니메이션을 본 독자에게 **진상/기존 Ghost Double 결말이 거의 겹침**. 2017 PS4 전 루트·트로피 완료 후기에서 수많은 **미회수 의문**을 구체적으로 지적.
- 주인공 유타의 독백이 장황하고 일상→사건 전개가 더뎌 실제 VN 템포가 애니의 압축된 속도와 별개로 느릴 수 있음.
- 몇 개인 엔딩이 짧고 비극적이며 반복 분기가 중복되어 인물 9명을 종합적으로 구원/설명하는 엔딩으로 연결되지 않는다.
- 2017 작품의 독립 서사 완성 문제를 해결할 새 **New World**가 2022년 취소된 점은 **실제 판본의 미완 인상**에 직접 영향을 줌. 다만 2017 Ghost Double 자체가 존재하지 않았다는 의미 아님.

## 4. 고유 게임 시스템: AFFI TRIGGER와 SKY SENSOR

### 아피 트리거(Affi Trigger)

1. 일상 대화 중 **블로그에 쓸 소재 키워드**를 포착할 때 선택해 보관한다. KENT 2017 평가에 따르면 **최대 9단어**까지 저장 가능.
2. 특정 타이밍에서 **블로그에 올릴 주요 키워드와 게시물**을 고른다.
3. 게시한 기사 소재에 따라 시나리오·일부 인물 루트·사건 전개가 달라진다.

**평가:** 일반적인 'A 선택/B 선택' 대신 **주인공이 운영하는 블로그의 게시물이 사람들의 운명을 바꾸는 구조**를 선택 시스템으로 만든 아이디어는 참신하다. 그러나 초반 선택 외에는 분기 폭이 제한되고 어떤 기사로 어떤 루트가 열리는지 미리 알기 어렵다. 실제 광고 수입·블로그 운영·조회수 KPI가 연동되는 경영 게임은 아님. [Gematsu 2017 기본 규칙](https://www.gematsu.com/2017/07/occulticnine-digital-title-japan-affi-trigger-system-introduced), [KENT 2017 실제 평가](https://kentworld-blog.com/archives/occulticnine-review.html).

### 스카이 센서(Sky Sensor)

- 라디오 주파수 다이얼을 조작해 별도의 **짧은 인형극/미니 애니메이션 マスターマストマーダー (MMM, 마스터 머스트 머더)** 콘텐츠를 탐색·수집한다.
- 초반부터 모든 MMM을 필수 수집하는 것은 아니지만 **실제 2017 트루 엔딩 Ghost Double 해금**을 위해서는 이전 MMM 20편 이상 감상, True Story에 등장하는 MMM 3편 모두 감상 등의 조건이 필요하다. [GameLine 직접 공략](https://gameline.jp/occultic-nine/%E6%94%BB%E7%95%A5%E3%83%81%E3%83%A3%E3%83%BC%E3%83%88/%E3%83%88%E3%82%A5%E3%83%AB%E3%83%BC%E3%82%A8%E3%83%B3%E3%83%89/).
- KENT의 기출시판 평가에서는 **약 30개의 MMM × 회당 약 5분**, 여러 엔딩 회수를 위해 미니극을 반복 탐색하는 구조를 불필요한 부담으로 감점했다. 일부 수집은 본편과 독립된 개그에 가까움.

### 실제 True Story와 취소된 후일담을 분리

**2017 원판에 실제 있는 것:** 미유우·아리아·토코 개인 엔딩을 거치면 열리는 **True Story**와 MMM 선택에 따른 End A/B/트루 엔딩 **Ghost Double**. [원판 True End 공략](https://gameline.jp/occultic-nine/%E6%94%BB%E7%95%A5%E3%83%81%E3%83%A3%E3%83%BC%E3%83%88/%E3%83%88%E3%82%A5%E3%83%AB%E3%83%BC%E3%82%A8%E3%83%B3%E3%83%89/).

**기획만 있던 것:** 미회수된 힌트·결말 이후 내용, 시리즈 다른 작품과의 연관성을 보강할 **새로운 True End/애프터 시나리오**와 Nintendo Switch 보강 이식. **2018 예고 → 2022 취소**. 현재 Switch나 기출시 3기종에서 플레이할 수 있는 완성 콘텐츠로 합산하면 안 된다.

## 7. 공식 한국어·기존 패치 및 기술 난이도

- **2017 일본 PS4·PS Vita·Xbox One판**은 일본어 게임으로 출시됐다. 한국어 게임 정식 제품명/지원 언어/한국어 배포 발표는 확인되지 않았다.
- **2026-10-12 공개 검색 범위:** Occultic;Nine·オカルティック・ナイン·오컬틱 나인·오컬틱나인과 한국어/한글패치/PSVita/PS4 조합으로 검색했지만 **제작자·버전·설치 파일·실사용 기록이 있는 공개 완성 게임 한글패치를 검증하지 못했다**. 비공개/삭제된 프로젝트가 없다는 뜻이 아니다.
- **한국어 소설과 애니메이션은 게임 대안이 아님:** S노벨 한국어 라이트노벨·한국 방송/자막 이력은 **2017 게임 본문 한국어화** 증거가 아니다.
