# Tantei Bokumetsu / Process of Elimination (탐정박멸) | Nintendo Switch 게임성·한글화 가치 평가

> **조사일: 2026-10-12 / Asia-Seoul. Nintendo Switch 일본 2021-05-27 및 북미 영어 2023-04-11·유럽 영어 2023-04-14 정식 출시 확인.**
>
> **자체 Switch 작품성 ⭐⭐⭐½☆ 3.5/5 / 🟢 신규 활성 한글화 후보 / 한글화 우선도 B / 기술 난이도 미확인.**
>
> **원제 探偵撲滅**을 일본에서는 Nippon Ichi Software가 2021년 PS4/Switch로, 서양에서는 NIS America가 **영어 공식 제목 《Process of Elimination》**으로 2023년 PS4/Switch에 출시한 **같은 본편**이다. 2021 일본판은 닌텐도 정식 일본어 전용, 2023 서양판은 영어 텍스트다. 공식 한국어는 두 Switch 지역판에서 모두 지원되지 않으며, 이번 공개 검색에서 이 게임용 실제 적용 가능한 완성 한국어 팬패치·한국어 게임판·2023 서양판 한국어 DLC의 원 제작자 배포/구동 증거를 찾지 못했다. 비공개/삭제 프로젝트까지 존재하지 않는다는 뜻은 아니다.
>
> **작품성 판단:** '14명 중 살인범이 숨어 있다'는 다인물 심리 서스펜스·관계/성장 드라마는 우수하지만, 전투 대신 격자형 턴 제한 **수사 시뮬레이션의 취소/실수 복구와 자유 저장 제약**, 긴 전반부 텍스트·후반 쉬워지는 수사, 일부 일본/영어 Switch 크래시 보고 때문에 **3.5점 B급**에 그친다. 2021 일본 패미통 **8+8+8+7=31/40(4명)**, 2023 서양 Switch 메타크리틱 **70/100(평론가 8명)**을 분리 평가하고 2023 영어판 특정 리뷰의 **실제 Switch 크래시 2회**도 적시한다. 제작사 2021-05-27 v1.0.1/06-07 v1.0.2로 특정 진행 불가 문제를 공식 수정했다. 최신 실행 버전·성능/한국어 ROMFS 구조는 **기기에서 직접 실측하지 않음**.

## 3. 스토리: 14명 탐정 중 살인마, 신뢰·희생·정의

국가 전체에서 100명 이상의 피해자를 만든 연쇄살인마 **八ツ裂き公(영문 공식 The Quartering Duke)**를 잡기 위해 **탐정동맹(Detective Alliance)**이라는 비범한 수사조직이 움직인다. 평범한 고등학생 **호조 카즈토(北條和都 / Wato Hojo)**는 탐정을 동경하다가 정체불명의 **노사 탐정(老師探偵 / Sage Detective)**의 초대를 받고 **모르그섬(Morgue Island)**의 탐정동맹 본부에 도착한다. 현장에는 이미 살인극이 벌어졌고 생존자 14명 중 범인이 숨어 있다. 본인의 자질이 부족하다는 이유로 **무능 탐정(Incompetent Detective)**이라는 탐정명을 받은 주인공은 **이상 탐정(Ideal Detective)** 등과 협력해 의혹을 벗고 동맹의 비밀과 자신의 과거를 밝혀야 한다.

**주요 탐정의 역할과 성격 차이**
- **무능 탐정/호조 카즈토:** 천재적 추리력 없이 동료의 재능·신뢰를 연결해 사건을 푼다. 무력감에서 책임으로 성장하는 이야기 중심축.
- **이상 탐정:** 사실상 동맹 리더, 이상주의적 수사와 주인공 신뢰를 대표. 주인공과 감정선이 가장 밀접한 중심 인물.
- **과학 탐정:** 높은 검증력과 특수 도구, 미숙한 동료가 풀기 힘든 고급 증거에 강함.
- **무장 탐정:** 추리 수치보다 타인의 추리를 증폭하는 연계력이 좋고 물리적 위험에 강함.
- **문학 탐정:** 독서·기억/세부 지각 능력을 가진 관찰 전문 인물. 제삼자 말투와 과거의 상처가 다른 탐정들과 대비.
- **마계 탐정:** 오컬트 전문 지식과 의심을 결합한 기이한 시각을 갖는 인물.
- **사축·시부야·미식·화족·야마토·외도·피학 탐정 등** 특기와 관점이 다른 다수의 인물 관계가 진행할수록 변함.

**스토리 강점**
1. **폐쇄된 섬+내부 배신자**라는 정통 클로즈드서클 미스터리 설정에 이상한 능력을 지닌 탐정들의 치열한 신뢰·배반·죽음을 겹침.
2. 14인의 가치관과 직업적 책임, 서로 다른 '정의'를 정면으로 충돌시켜 후반부 주인공 성장과 범인 해명에 감정적 보상.
3. 과거 사건과 잔류 사념/도감의 단서가 후반 사건을 이해할 때 의미를 갖는 복선 구조. 초반 세계관은 과장돼 보여도 실제 사건의 진상으로 연결되는 점 호평.
4. 전체 사건은 마무리되는 편이며 탐정명/본명과 복잡한 관계 속 신뢰·불신이 결말의 몰입을 높임.

**스토리 단점**
1. 초반의 다수 탐정 소개·독특한 별명/장황한 설명 때문에 실제 사건/조사까지 오래 걸림.
2. 일부 인물은 직업/성격을 크게 과장한 전형적 '기믹 캐릭터'로, 개별 감정선의 강약 편차.
3. 《단간론파》와 비슷한 장르적 기대를 받지만 재판/대화 대결의 규모와 상호작용은 더 작음.
4. 후반 특정 전개는 복선 추리보다 전형적 반전 예측이 쉽다는 완주 후기도 있다. **범인 정체는 상세 보고서에서도 공개하지 않음**.

## 4. 게임플레이: 3단계 이야기 + 제한 턴 전술형 수사

본작은 **탄막·던전 탐험/전투를 하는 게임이 아니다.** 수사의 전술적 편성은 실제 적과 HP/공격력/경험치를 주고받는 SRPG 전투가 아닌 **격자 위 조사·단서 검증·추리력 배분 퍼즐**이다.

| 단계/시스템 | 정확한 작동 | 작품성 평가 |
|---|---|---|
| 어드벤처 파트 | 일본어 풀보이스 주요 대사/입체적인 인물 소통·선택지. 탐정의 관계, 사건, 협력/의심 전개 | 대부분 시간은 텍스트 독서. 인물극 호평, 읽는 파트가 조사에 비해 긴 문제 |
| 수사 시뮬레이션 파트 | 격자 위 여러 탐정 유닛 **이동·조사·검증·추리·연계**. 탐정마다 능력치·이동/조사 범위 차이 | 정통 추리 ADV를 작은 전술 퍼즐로 구현한 독특한 시스템 |
| **에비던스 스퀘어(ES)** | 현장의 수상한 칸을 조사해 **증거품** 획득 | 조사를 잘하는 캐릭터의 긴 범위가 이동 턴 절약 |
| **검증(検証)** | 증거품의 진위/복잡도에 맞춰 검증 능력 높은 탐정에게 분석. 완료하면 새 목표 또는 잠긴 추리 가능 | '증거 확보 → 분석 → 다음 의문 열림'이라는 단계적 수사 |
| **미스터리 포인트(MP)** | 추리력 수치로 의문의 해명값을 전부 깎아 소거 | 공격 수치처럼 보이지만 실제 **논리 해결도**. 진짜 전투 HP라 쓰지 않음 |
| **연계·추리공명** | 다른 탐정을 인접시키면 연계력만큼 주 탐정의 추리 수치 증가 | '연구/추리 전문가와 보조 인물'을 합치는 편성 퍼즐 |
| **데드 헤링(DH)** | 라운드 종료 시 해당 칸에 남은 탐정이 사망하는 등의 함정, 추리로 해제 가능 | 시간제한과 턴 순서 긴장. 방치 시 게임오버 |
| 탐정 개입·선행 수사 | 일부 동맹원은 처음엔 플레이어 지시를 듣지 않고 독자 행동. 스토리/신뢰 진척 뒤 행동에 **개입**, **선행 수사**로 지정 인원만 움직여 순서 세밀 제어 | 주인공이 실제 '통솔하는 탐정'으로 성장하는 시스템 표현. 강제 자율 이동이 답답할 수 있음 |

**수사 부분의 실제 단점:** 새 조사 대상이 수사 도중 드러나므로 매번 처음부터 모든 수를 최적화할 수 없고, 행동 취소가 어렵다. 일부 맵에 캐릭터가 겹치면 맵 회전 미지원으로 위치 확인이 힘들다. **수사 파트부터 진상 규명 완료까지 긴 구간에 자유 저장이 막혀**, 실수와 크래시 시 이미 본 대화/맵을 다시 보는 일이 생긴다. 일본 2021 및 영문 2023 직접 리뷰에서 공통 지적. 2021·2023 일부 완주자는 **초반보다 후반이 쉬워지는 추리 맵**도 단점으로 평가한다.

## 5. 장점과 단점

**장점**
1. **다인물 폐쇄형 미스터리의 흡인력:** 서로 다른 신념·살인마 의혹/의심·잔류 사념이 만들어 내는 복선과 반전.
2. **특기별 수사 운영:** 추리력 대신 검증/연계/이동 능력이 다른 인물에게 명령하며 탐정이 협력하는 과정 자체를 플레이로 구현.
3. **캐릭터·일본어 보이스:** 특색 있는 14명, 별도 탐정 프로필/서브 사건 글, 매력적인 2D 포트레이트와 일본 성우 연기.
4. **증거 검증 후 추리 가능/함정 회피의 턴 퍼즐:** 《역전재판》과 구별되는 실제 수사 시간 배분, 고난도 선택 보상.
5. **공식 영어 현지화 Switch:** 원 일본어를 읽지 못해도 2023 영어 Switch판에서 이야기 접근 가능, 영어 번역본과 일본어 원문을 용어 검수에 교차 활용 가능. **영어판은 한국어판이 아님**.

**단점**
1. **긴 읽기 구간·초기 설명 부담:** 실제로 작동하는 추리/수사 게임이 나오기까지 매우 많은 대사를 읽으며 세계관/탐정 수가 많아 초반 진입이 느리다.
2. **전술 퍼즐의 게임성 한계:** 행동 돌이키기·맵 회전/겹친 인물 보기 불편, 예상 못 한 새 단서, 퍼즐 후반 난도 하락.
3. **제한 저장 + 실제 크래시 제보:** 일본 2021 진행 불가 버그 패치 공지 이후에도 2023 영어판 리뷰어가 강제 종료 2회 경험. '현행 모두 크래시'는 아님.
4. **일부 과장된 캐릭터와 독창성 편차:** 《단간론파》 등과 유사한 데스게임 기법, 일부 개그/특기 설정의 단선성과 감정선 편차.
5. **이야기/대사 연출이 오래 유지되는 반복 이미지:** 긴 텍스트 대비 큰 CG/캐릭터 표정 변화가 많지 않아 몰입 저하.
6. **전투/퍼즐 볼륨 기대 불일치:** 14명 전술 수사라고 소개돼도 일반 전략 게임 수준의 성장·스킬 육성/자유로운 탐험은 없다.
