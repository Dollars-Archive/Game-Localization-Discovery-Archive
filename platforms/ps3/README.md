## 현재 선정 후보

작품성은 기존의 **5점 척도·0.5점 단위**, 개인 추천은 **1~10점·소수 첫째 자리**입니다. 개인 추천은 직접 플레이 후기나 외부 평점의 기계 환산이 아닌 자료 기반의 주관적 편집 판단입니다. 작품성 등록선과 한국어 대안 자격을 먼저 확인한 뒤 적격 작품 중 30개를 선정했습니다.

개인 순위는 **2026-10-08의 기존 55개 심사 대상 기준**입니다. 이후 2026-10-12 추가한 《WHITE ALBUM2》는 한국어 대안 확인으로 예비에 보존했습니다. **2026-10-17 사용자 명시 요청으로 《차륜의 나라, 해바라기의 소녀》를 이 기본 PS3 화면에 표시합니다.** 작품성 4.5/5·신규 개인 추천 8.3/10을 기록하되 기존 55개 역사 순위는 변경하지 않고 개인 순위는 미부여입니다. Windows 원작 한국어 번역 대안으로 신규 콘솔 한글화 활성 대상이 아니므로, 이 1건은 **작품 평가 표시용 사용자 지정 예외**입니다. 30개 표시 한도를 지키기 위해 기존 개인 34위 《XBLAZE Code: Embryo》를 예비로 옮기되 해당 작품의 7.1점·34위·별점·문서·찜 키는 그대로 보존했습니다. 예비는 기본 목록·집계에서 제외하며 별도 보기와 내 목록에서 접근할 수 있습니다.

**2026-10-17 신규 《마브러브 photonmelodies♮》 PS3판을 기본 30개 목록에 작품성 3.5/5·개인 추천 7.8/10·한글화 B로 추가했습니다.** 기존 55작품의 개인 순위는 유지하며 이 신규 작품은 역사 순위를 미부여했습니다. 이전 개인 32위 《Koihime Enbu》는 예비 기록으로 이동하되 7.2점·C급·찜·상세 MD를 유지합니다.
