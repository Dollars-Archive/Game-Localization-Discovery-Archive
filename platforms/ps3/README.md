## PS3 등록 운영

- 이 구역의 조사·등록 대상은 **PS3판**입니다. 원제·부제·시리즈 순번·실제 발매 기종을 먼저 확인하고 다른 플랫폼 판본과 혼동하지 않습니다.
- 작품성 기준은 루트 README와 동일합니다. 독점·희소성·추가 콘텐츠·취향 적중만으로 점수를 가산하지 않으며, 평가 근거가 부족한 작품을 관성적으로 3.5점에 넣지 않습니다.
- 공식 한국어판, 공개 PS3 유저 한글패치, 다른 플랫폼의 한국어판·한글패치를 구분하고 작품별 실제 조사일을 기록합니다.
- PS2·PS4·PS Vita·PC 등 다른 판본과 PS3판의 추가·삭제 콘텐츠, 성능, 해상도, 언어 지원을 비교합니다. 다른 플랫폼의 평점을 PS3 단독 평점처럼 옮겨 적지 않습니다.
- **발굴 추천도 / 한글화 우선도 / 기술 난이도는 별도 축**입니다. 실제 게임 파일 또는 신뢰할 만한 해당 판본 기술 분석 전에는 기술 난이도를 `미확인`으로 유지합니다.
- 같은 PS3판의 지역판·재판·제목 표기 차이는 중복 확인 후 하나의 문서에서 관리합니다.
