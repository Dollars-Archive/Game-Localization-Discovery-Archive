## 이번 목록의 선별 기준

- 메타크리틱 평론가 점수와 PS3 사용자 점수를 50%씩 반영했습니다. 통합점수 = (메타스코어 + 사용자 점수 × 10) ÷ 2. 1차 통과 하한은 70점입니다.
- 점수 통과작은 정확히 30개이며, 통합점수를 발굴 추천도 별점으로 자동 환산하지 않았습니다. 작품 별점은 전부 미평가입니다.
- 슈팅·스포츠·격투는 제외하고, 일본 만화·애니풍·비주얼노벨·턴제 및 덜 알려진 작품을 우선했습니다. Super Puzzle Fighter II는 격투가 아니라 매칭 퍼즐입니다.
- 확인된 다른 판본 한국어 대안이 있는 제목은 제외했습니다. 국내 패키지 유통과 게임 내 한국어를 구분합니다.
- 『영웅전희』는 사용자의 요청으로 한글화 우선도 A에 두었습니다. 그 외 A/B/C는 2차 오디션 편의용 임시 우선도입니다.
- 『박앵귀』는 평론가 점수가 tbd라 통합점수를 계산하지 않은 별도 와일드카드이며 30개에 포함하지 않습니다.
- 공개 목록에서 못 찾았다는 사실은 비공개·미등록 패치가 없다는 증거가 아닙니다. 타 플랫폼 대안 확인도 대표 이식판 중심의 제한 조사입니다.
