## 이번 목록의 선별 기준

- 메타크리틱 평론가 점수와 사용자 점수를 50%씩 반영해 통합점수 70~100점을 1차 통과로 봤습니다. 통합점수 = (메타스코어 + 사용자 점수 × 10) ÷ 2.
- 사용자가 제외한 격투·슈팅·스포츠 장르와 확인된 타 기종 한국어 대안이 있는 작품은 활성 후보에서 제외했습니다.
- 비주얼노벨·턴제·JRPG 및 만화·애니풍·마이너 작품을 우선했습니다. PS Vita 작업의 4.0점 이상 제외와 30개 제한은 적용하지 않았습니다.
- 발굴 추천도는 외부 점수와 별도 축입니다. 『영웅전희』는 사용자가 직접 등록을 요청해 한글화 우선도 A로 두었습니다.
- 『박앵귀』는 메타스코어가 tbd라 통합점수를 계산하지 않았습니다. 선호한 비주얼노벨 와일드카드로 별도 표시합니다.
- 공개 PS3 한글패치 목록에 제목 일치 여부를 대조했습니다. 목록에 없다는 점은 비공개·미등록 패치까지 없다는 확정이 아니며, 상세 문서에 판본별 확인 범위를 적었습니다.
